# 逆向资料/下载分析 —— 目录索引与结论摘要

本目录存放「VSCode 写 Python → 无线下载到 SKCON9」功能的技术底稿：官方软件（AbilixScratch3.0，Unity + xLua）下载链路的逆向文档、SKCON9 手册 WiFi 原文摘录、字节级协议规格，以及最初的临时提取文件。

## 结论摘要（10 条）

1. **下载本质**：Python 源码在 PC 本地打成 `download/<程序名>.py.zip`（单条目 `<程序名>.py/<程序名>.py`、deflate 6），整个 zip 通过 TCP 发给机器人（appType=3、fileType=21）。
2. **两条 TCP 连接**：心跳/控制 `机器人IP:10086`，文件传输 `机器人IP:8890`；两条都连上才能发文件，发文件期间暂停 10086 心跳、结束恢复。
3. **帧格式**：`AA 55 | 长度高 | 长度低 | [type][cmd1][cmd2][0][r][0][seq] + data | 校验和`；长度字段 = 帧总长−4（数据块 10240 字节时高字节非 0，为 `28 08`）；校验和 = 前面所有字节和 & 0xFF。
4. **心跳**：连上发 `cmd(0,2)`，之后每秒 `cmd(0,4)`；机器人回 `160,4` 且 type 必须=111；约 8 秒无应答判超时。
5. **文件传输**：`cmd(1,1)` 请求（长度/CRC32/`<程序名>.py.zip`）→ 机器人回 160,1 → `cmd(1,3)` 每块 10240 字节 → `cmd(1,4)` EOF → 160,3 成功；CRC 错 160,2、文件已存在 160,7。
6. **重要修正**：WiFi 数据块/结束帧的 type 取 `Constants.ROBOT_CONNECTED`（未扫描时默认 **0**，请求帧才是 111）；官方 TCP 路径**没有**逐块停等/传输超时；文件名用 `Encoding.Default`（中文 Windows=GBK）而非 UTF-8。
7. **zip 结构**：真实产物已逐字节核对（9 个样本）——单条目、deflate、无注释、内层 `.py` 无 BOM；CRC32 与 zlib 一致。
8. **文件头**：`#<SKCON9><USB><ProgramName>` 是 Web 编辑器拼的注释行；官方有效路径下连接方式标签恒为 `<USB>`（不反映真实 WiFi/USB），C# 全文不解析该行，下载协议不依赖它。
9. **手册缺口**：SKCON9 手册的无线下载步骤写在 §4.1 Abilix Chart 3.0（p20-22），§4.2 Abilix Scratch 3.0 只有「敬请期待！」（p39）——Python 无线下载操作/协议必须靠代码推断。
10. **可行性**：机器人侧只认 TCP 帧协议 + zip，zip 是纯客户端产物，因此 VSCode 工具可按规格文档复刻客户端、无需启动官方软件；未真机验证项见《下载链路逆向.md》§9。
