# 逆向资料收录范围

本目录只保留了 **下载链路/协议分析**（`下载分析/`）。以下官方软件提取物没有进入仓库：

- `decompiled/Assembly-CSharp.decompiled.cs`（约 12 万行）
- `关键源码/`（官方 JS 生成器/积木定义）
- `xlua明文/`（497 个 Lua）
- `apk_assets/`、`apk_controller/`、`通用数据/`

原因：版权不属于本项目，且体积大。需要查原始证据时，请在自己安装的
`AbilixScratch3.0 1.0.3.4` 上运行 `unpack_zfb.py` 重新解包。

本目录保留的 `下载分析/` 里引用到的 C#/Lua 行号仍然可用——它们对应你自己的
本机安装，而不是仓库里的副本。
