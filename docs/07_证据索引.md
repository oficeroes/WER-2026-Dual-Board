## 5. 怎么复现

1. 读主报告 §0.0（A–H）；
2. 在机器人上跑实验 05，确认 `socket=0`；
3. CH340 跑实验 09，确认握手；
4. 用实验 14 下发 C 程序，PC 监听 12345；
5. 两板各跑 W5 server/client，PC 监听 8888；
6. 按 [`04_安装步骤.md`](04_安装步骤.md) 装「我的函数 + 双板通讯」，拖 4 个积木做积木层验证。
