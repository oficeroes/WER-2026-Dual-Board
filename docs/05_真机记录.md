| 项 | 结果 |

→ 纯 Python WiFi 方案关闭；需要 C 用户程序。

## 2. USB-C = CH340 串口

设备：

| 项 | 值 |
|---|---|
| 名称 | `USB-SERIAL CH340 (COM3)` |
| VID/PID | `USB\VID_1A86&PID_7523` |
| 驱动 | CH340 3.9.2024.9 |
| `adb devices` | 空（不是 ADB） |
| 波特率 | **937500 8N1**（官方 `LibUart`） |

握手（`实验/实验09_有线握手_CH340.py`）：

```text
发：AA 55 00 08 6F B0 01 00 00 00 01 28
收：AA 55 00 09 6F B0 01 00 00 00 00 01 29
```

判据（官方 C#）：`recv[5]==0xB0 && recv[6]==0x01 && recv[11]∈{1,40}` → **握手成功**。

## 8. 已知的时间/环境差异

- 以上是**开发机 + 用户真机**的结果；换路由器/换固件/换电池可能不同。
- WiFi 速率是 4 KB 回显测的**双向吞吐近似值**，不是 iperf 级别的精确带宽。
- 机器人同一时刻只能跑一个用户程序；两板各跑一个，互不影响。
- 程序需要手动在机器人屏幕上启动；没有远程自动起跑。

## 9. 复现顺序

1. 读 `双板通讯研究/README_可行性研究主报告.md` §0.0；
2. 在机器人上跑 `实验05_运行环境探测.py`，确认 `socket=0`；
3. 用 CH340 跑 `实验09_有线握手_CH340.py`；
4. 用 `实验14_W4_C程序下发.js` 下发 C 探针；
5. 两板各跑 `W5SERVER.c` / `W5CLIENT.c`，在 PC 上监听 8888；
6. 按 [`04_安装步骤.md`](04_安装步骤.md) 安装原生积木，做积木层验证。
