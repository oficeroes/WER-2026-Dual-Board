# 06 · 排错与限制

## 1. 先判断“卡在哪一层”

双板通讯有 5 层，排错要一层一层来：

```text
① 两块板在同一 WiFi、能互 ping
② 程序里设置了对方的 IP
③ 程序里用了「双板通讯」积木（prelude 被注入）
④ C 助手编译/启动成功（屏幕 err=[]）
⑤ 对方程序正在运行、地址一致
```

| 现象 | 最可能卡在 | 怎么查 |
|---|---|---|
| 两块板互相 ping 不通 | ① | 机器人屏幕看 IP；路由器看客户端列表；关 AP 隔离 |
| 屏幕 `err` 不是 `[]` | ④ | 看错误信息；可能是 gcc 编译失败/目录不可写 |
| 一直收到 0 | ③⑤ | 对方没在跑程序；IP 填错；地址不一致 |
| 一收一停 | ⑤ | 对方程序退出了；机器人同一时刻只能跑一个程序 |
| 装完 IDE 没有「双板通讯」 | 安装 | 看安装日志；确认 IDE 已关闭、UAC 点了「是」 |

## 2. 安装类问题

| 现象 | 原因 / 处理 |
|---|---|
| 双击 `.cmd` 一闪而过 | UAC 点了「否」；重新双击，点「是」 |
| `[NOT APPLIED] Administrator rights were not granted` | 没给管理员权限；右键以管理员运行 |
| 提示「IDE 正在运行」 | 任务管理器结束 `AbilixScratch3.0.exe` |
| `找不到补丁包 browser_assets.patched` | 还没构建；先做安装步骤第 3 步 |
| 构建报“找不到 `abilixUserLibPython`” | 当前资源包不是「我的函数」补丁；先装「我的函数」 |
| 构建报“原版备份不存在” | 第 2 步没成功；重新装「我的函数」，它会生成备份 |
| `当前资源包既不是原版也不是已知旧补丁版` | 装过别的补丁；先 `还原原版.cmd` 再装 |
| 装完 IDE 打不开 | 运行 `restore_dual.cmd` 回滚；把报错发出来 |
| 软件升级后补丁消失 | 重新做安装步骤；大版本原版 sha 会变，先备份 |

## 3. 运行类问题

| 现象 | 原因 / 处理 |
|---|---|
| 对方没运行程序也能收吗？ | 不能。对方必须有代码在跑（任意含双板通讯积木的程序） |
| 两块板能同时跑两个程序吗？ | 不能。机器人 RunningService 单实例；先跑 server 再跑 client 会把 server 顶掉 |
| 能远程自动起跑吗？ | 没找到 `startRunning` 远程入口；目前屏幕手动点 |
| 地址 1 被占用了 | 地址 1~128 与「读写数据」共用；换 11/12 等空地址 |
| 能传文本/浮点吗？ | 当前是整数 −99999~99999；文本/浮点自己编码成整数（例如 ×100） |
| 重启后值变 0 | 从没写过的地址是 0；写过才会回读。用「保存到读写数据」立即写 |
| 写 EEPROM 太频繁会坏吗？ | 自动节流：同一地址最快 1 秒一次、只在变化时写；不要手动高频写 |
| 换 WiFi 后收不到 | 重新设置两块板的 IP；机器人 IP 可能变了 |
| 速率不稳定 | 2.4G 干扰、距离、路由器；4 KB 回显是近似值 |

## 4. 平台/安全限制

1. **8890/10086/7777/9999 无鉴权**：只在**自己队伍的设备**上实验；不要干扰/攻击其他队伍。
2. **不要改 Android / root / 刷机**：风险高、可能变砖；比赛设备不值得。
3. **不要用 testkey / system UID / ADB**：理论路径存在，但本项目**没有执行**，也不建议在比赛设备上尝试。
4. **不要用 8890 路径穿越/任意写**：那是安全研究，不是比赛功能。
5. **不要把官方安装包资源再分发**：仓库只保留我们自己写的文档/代码/证据。

## 5. 什么时候该回滚

- IDE 启动异常、积木区白屏、分类消失；
- 安装脚本报 sha 不符；
- 软件升级/重装后；
- 换电脑/换 IDE 版本。

回滚顺序：

```text
restore_dual.cmd      # 回到「我的函数」版
还原原版.cmd           # 回到原版
```

## 7. 仍待解决

- 双板通讯的**协议版本/错误处理**还比较简陋：目前是“地址→最新值”，没有 ACK/重传/序号。
- 没有**自动起跑**；比赛现场要预留手动启动时间。
- 没有**后台常驻**；对方程序退出就收不到。
- 没有**加密/鉴权**；只适合自己队伍的设备。
- 没有**多播/组播**；目前是一对一（设置对方 IP）。
