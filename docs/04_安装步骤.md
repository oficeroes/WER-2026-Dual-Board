# 04 · 安装步骤

> 这是**源码安装**流程：仓库里不带 85 MB 的 `browser_assets.patched`，补丁在你自己的电脑上生成。
> 适用于：Windows 10/11 + `AbilixScratch3.0 1.0.3.4` + 两块 SKCON9。

## 0. 准备清单

| 需要 | 说明 |
|---|---|
| Windows 10/11 | 64 位 |
| AbilixScratch3.0 | **1.0.3.4**（默认装在 `D:\Program Files\AbilixScratch3.0`） |
| Python 3.8+ | 建议 3.12；命令行里能运行 `python` |
| Chrome 或 Edge | 生成函数定义 prelude 用（无头浏览器） |
| 管理员权限 | 安装/还原要替换 `Program Files` 下的资源包 |
| 两块 SKCON9 | 同一 2.4G WiFi；能互相 ping 通 |
| 备份意识 | 安装前会自动备份原版资源包；不要删 `备份/` |

> **只想读代码/看研究**：不用安装，直接看 [`01_我们做了什么.md`](01_我们做了什么.md)、[`02_双板通讯原理.md`](02_双板通讯原理.md)。

## 1. 关闭 IDE

完全退出 `AbilixScratch3.0`（任务管理器里不能有 `AbilixScratch3.0.exe`）。
安装脚本会检查；IDE 开着会拒绝执行，防止装坏。

## 2. 先装「我的函数」（双板通讯的前置）

双板通讯的 4 个块和「我的函数」共用同一套 `abilix_userlib.js` 机制，所以**必须先让 IDE 有「我的函数」分类**。

双击：

```
WER_函数库\工具\原生积木\安装原生积木.cmd
```

会发生什么：

1. 普通权限窗口：解包资源包 + 用无头 Chrome 跑 IDE 自己的 Blockly 引擎生成函数定义（约 10~30 秒）；
2. 然后弹 **UAC**：点「是」；
3. 脚本备份原版 → 替换 → 校验 sha256；
4. 看到 `[DONE]` 后按任意键关闭。

> 如果这台电脑没有 Chrome/Edge，或不想装 Python：
> - 用便携版：`WER_函数库\工具\原生积木\便携版\说明.md`（复制一份软件到用户目录再打补丁，不需要管理员）；
> - 或用离线包：`WER_函数库\安装包\README_离线安装.txt`（仓库不带 85 MB 的 `browser_assets.patched`，需要在本机重新构建，见该说明）。
>
> **第一次失败最常见的原因**：UAC 弹窗点了「否」，或者 IDE 没关。

装好后打开 IDE → 积木编程 → 左侧应出现紫色「我的函数」。
先不要急着装双板，继续下一步。

## 3. 生成「双板通讯」补丁

在项目根目录运行（普通权限，不需要管理员）：

```bat
python WER_函数库\工具\双板通讯\构建双板通讯扩展.py
```

它会：

- 读取 `WER_函数库\工具\原生积木\备份\browser_assets.原始.<sha>.bin`（第 2 步自动生成的原版备份）；
- 读取当前已安装资源包里的「我的函数」prelude；
- 合并双板通讯 prelude；
- 输出到 `WER_函数库\安装包_双板通讯\`：
  - `browser_assets.patched`（约 85 MB，**只在本机生成，不进 Git**）
  - `install_dual.cmd` / `install_dual.ps1`
  - `restore_dual.cmd` / `restore_dual.ps1`
  - `安装信息.txt`

如果 IDE 装在别处：

```bat
python WER_函数库\工具\双板通讯\构建双板通讯扩展.py --assets "你的\...\Resources\browser_assets"
```

也可以先用环境变量：

```bat
set WER_ASSETS=D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets
```

> 构建失败并提示“已安装补丁里找不到 `abilixUserLibPython` / `abilixUserLib`”：
> 说明第 2 步没成功（当前资源包不是「我的函数」补丁）。回到第 2 步，确认 IDE 左侧有「我的函数」。

### 快捷方式

也可以双击：

```
tools\安装双板通讯积木.cmd
```

它等于「检查 + 构建 + 调 install_dual.cmd」，但**仍然要求第 2 步已经完成**。

## 4. 安装「双板通讯」补丁

双击（或右键以管理员身份运行）：

```
WER_函数库\安装包_双板通讯\install_dual.cmd
```

会发生什么：

1. UAC → 点「是」；
2. 检查 IDE 已关闭；
3. 检查当前资源包 sha 是“原版”或“构建时读到的「我的函数」版”；
4. 备份当前资源包到 `WER_函数库\工具\原生积木\备份\browser_assets.双板通讯前-<时间戳>.bin`；
5. 替换 → 校验 sha256 → 失败自动回滚。

看到 `安装成功` 后打开 IDE：

- 左侧「我的函数」旁边应多出 **「双板通讯」** 分类；
- 里面有 4 个块：设置对方主板 IP / 发送…到地址 / 接收地址…的信息 / 把地址…的信息保存到读写数据。

## 5. 两块板最小验证

1. 两块板连同一个 2.4G WiFi（手机热点也行，注意频段）；
2. 在机器人屏幕/路由器里查到两块板的 IP，例如 A=`192.168.1.102`，B=`192.168.1.103`；
3. A 板程序：

   ```text
   设置对方主板 IP [192.168.1.103]
   永远重复 {
       发送 [计数器] 到地址 [11]
       在屏幕显示 接收地址 [12] 的信息
   }
   ```

4. B 板程序：

   ```text
   设置对方主板 IP [192.168.1.102]
   永远重复 {
       发送 [计数器] 到地址 [12]
       在屏幕显示 接收地址 [11] 的信息
   }
   ```

5. 两块板各运行自己的程序；屏幕应互相显示对方递增的数值；
6. 掉电保持：B 收到 A 的数值后，关掉 B 的程序再运行，B 的“接收地址 11”会先显示上次的值。

> 地址建议用 11、12（空地址），避免覆盖已有的「读写数据」（例如 01=3600、02=400 这类标定值）。

## 6. 还原

### 只撤双板通讯，保留「我的函数」

双击：

```
WER_函数库\安装包_双板通讯\restore_dual.cmd
```

它会用最近一次「双板通讯安装前」的备份回滚（回到「我的函数」版本）。

### 全部还原到原版

双击：

```
WER_函数库\工具\原生积木\还原原版.cmd
```

它会用原版备份回滚。还原后「我的函数」和「双板通讯」都会消失。

> 两个备份别删：
> - `browser_assets.原始.<sha>.bin`：原版；
> - `browser_assets.双板通讯前-<时间戳>.bin`：双板安装前的「我的函数」版。

## 7. 排错

| 现象 | 处理 |
|---|---|
| 双击 `.cmd` 一闪而过 | 看是不是 UAC 点了「否」；重新双击并点「是」 |
| `[NOT APPLIED] Administrator rights were not granted` | 没给管理员权限；重新运行，UAC 点「是」 |
| 提示「IDE 正在运行」 | 任务管理器结束 `AbilixScratch3.0.exe`，再运行 |
| 提示「找不到补丁包 browser_assets.patched」 | 先做第 3 步构建；仓库不带 85 MB 补丁 |
| 构建报“找不到 `abilixUserLibPython`” | 先做第 2 步安装「我的函数」 |
| 构建报“原版资源包备份不存在” | 先做第 2 步；它会生成 `备份/browser_assets.原始.*.bin` |
| 安装报“当前资源包既不是原版也不是已知旧补丁版” | 当前 IDE 装过别的补丁；先用 `还原原版.cmd` 回滚再装 |
| 装完 IDE 打不开/分类没出现 | 运行 `restore_dual.cmd` 回滚；把关窗报错发出来 |
| 两块板收不到 | ① 两块板都在跑程序；② IP 互指；③ 同一 WiFi；④ 地址没被占用；⑤ 屏幕 `err=[]` |
| 构建时无头 Chrome 起不来 | 用普通权限运行构建（不要在管理员窗口里跑编译）；确认 Chrome/Edge 已安装 |
| 软件升级/重装后补丁消失 | 重新做第 2~4 步；升级大版本后原版 sha 变了，先备份 |

## 8. 版本/路径说明

- 工具按 `AbilixScratch3.0 1.0.3.4` 的原版资源包 sha256 校验；版本不同会警告，但仍可编译（会先备份新版本资源包）。
- 默认安装路径：`D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets`。
- 装在别处：构建时用 `--assets`；安装时用 `install_dual.ps1 -Target "你的路径"`（或先设 `WER_ASSETS`）。
- 跨版本**不要**用旧版本的备份还原新版本软件。

## 9. 安全边界

- 8890/10086/7777/9999 无鉴权；只在自己队伍的设备上做实验。
- 不要用这些通道干扰、篡改、攻击其他队伍的设备。
- 改 Android / root / testkey / ADB 风险高；本项目没有执行，也不建议在比赛设备上尝试。
