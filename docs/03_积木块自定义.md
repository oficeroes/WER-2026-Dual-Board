# 03 · 积木块自定义：为什么左侧会多出「我的函数」和「双板通讯」

> 这一页讲“怎么把自定义积木塞进 IDE 内部”，也是双板通讯 4 个积木的实现基础。
> 更细的原理/回滚/换电脑见 `WER_函数库/修改软件说明/`。

## 1. 目标

用户的原话：

> 可不可以你提前写好一些函数，然后当我打开这个 IDE 的积木编程时，就能直接在函数上看到这些积木块，直接拖下来就能用？

要求不是“新建项目时自动塞一段代码”，而是：

- 左侧分类栏里**真的多出一个分类**；
- 里面的块能像官方积木一样**拖拽、拼参数**；
- 拖进程序后，右侧 Python 面板自动带 `def` 和调用；
- 不用在项目之间复制粘贴函数定义。

## 2. 关键发现：IDE 的积木页面是一个打包的 Web 应用

`AbilixScratch3.0` 的积木页面在：

```
D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets
```

它是一个自定义 **`zfbRes_v1` 归档**（无压缩，6,645 个条目），里面是：

- `Blockly_Code/maingui.html` —— 页面外壳 + 3 个型号的工具箱 XML
- `Blockly_Code/maingui.js` —— 页面逻辑 + `getPythonCode()`
- `Blockly_Code/generators/*.js` —— 各积木的 Python 生成器
- `Blockly_Code/procedures.js` —— 函数名自动加 `func_`
- `Blockly_Code/custom-dialog.js` —— 变量名自动加 `var_`

所以不需要改项目文件、不需要改新建模板：**把块注册进 IDE 自己的 Blockly 环境**即可。

## 3. 只改 4 个条目

| # | 条目 | 改动 | 作用 |
|---|---|---|---|
| 1 | `/Blockly_Code/maingui.html` | ① 插入 `<script src="abilix_userlib.js"></script>`；② 在 3 个工具箱 XML 末尾插入「我的函数」/「双板通讯」分类 | 让页面加载新 JS；让左侧出现分类 |
| 2 | `/Blockly_Code/abilix_userlib.js`（**新增**） | 注册 `Blockly.Blocks['abilixuf_*']`（外形/参数/颜色/提示）+ `Blockly.Python['abilixuf_*']`（生成调用）+ 函数定义 prelude + 元数据 | 决定块长什么样、生成什么代码 |
| 3 | `/Blockly_Code/maingui.js` | 在 `getPythonCode` 拼接代码的两处，改成**条件注入**：只有工程里存在 `abilixuf_*` 块时才注入 prelude | 不含自定义块的项目输出与官方**逐字节一致** |
| 4 | `/Blockly_Code/abilix_userlib.json`（**新增**） | 补丁清单：工具版本、构建时间、函数库 hash、函数列表、原始资源包信息、4 个条目的 size/sha256 | 状态检查、是否需要重装、还原前核对 |

条件注入的关键代码（`maingui.js` 中恰好 2 处）：

```js
((typeof abilixUserLibPython !== "undefined" &&
  workspace && workspace.getAllBlocks &&
  workspace.getAllBlocks().some(function(b){ return (b.type||"").indexOf("abilixuf_")===0; }))
    ? abilixUserLibPython : "") +
Blockly.Python.workspaceToCode(workspace) +
```

效果：

- 工程里有 `abilixuf_*` 块 → 注入 `def func_xxx(...)`；
- 没有 → 注入空串，输出和官方原版**逐字节一致**。

## 4. 为什么可以放心用：逐字节回归

| 场景 | 结果 |
|---|---|
| 不含自定义块的真实工程 `PI.srhs` | 打补丁后生成 **50,618 B**，sha256 `30a0bab0…`，与官方黄金样本 `PI.py` **逐字节一致** |
| 含 1 个自定义块的最小工程 | 32/32 断言通过；生成 203 B；prelude 61 字符 |
| 含 20 个自定义块（11 个带参）的工程 | 32/32 断言通过；生成 15,544 B；调用/参数/prelude/py_compile 全对 |
| 打补丁的资源包 | 6,647 条目；**4 个条目改动/新增，其余 6,643 个逐字节不变** |

补丁大小：原版 85,271,033 B → 补丁后 85,274,935 B（+3,902 B，约 3.9 KB）。

## 5. 双板通讯的 4 个块

双板通讯扩展是在「我的函数」机制上再加：

```text
「双板通讯」分类
├─ 设置对方主板 IP [192.168.1.103]
├─ 发送 [值] 到地址 [1]
├─ 接收地址 [1] 的信息        （reporter，可当变量）
└─ 把地址 [1] 的信息保存到读写数据
```

生成的 Python：

```python
_wl_set_ip('192.168.1.103')
_wl_send(1, value)
_wl_recv(1)          # 返回最新值
_wl_save_ee(1)       # 立即写 EEPROM
```

这 4 个块和「我的函数」共用同一个 `abilix_userlib.js` / `abilix_userlib.json` / 条件注入逻辑。
构建脚本会把「我的函数」的 prelude 和「双板通讯」的 prelude 合并，再重新打包。

## 6. 构建/安装流程（简述）

```text
我的函数库.srhs
   │ ① 解析所有 procedures_defnoreturn → 名字/参数
   ▼
函数清单
   │ ② 用无头 Chrome 跑 IDE 自己的 Blockly 引擎 → 生成 prelude
   ▼
prelude（函数定义 Python 源码）
   │ ③ 生成 abilix_userlib.js：块定义 + Python 生成器 + prelude
   │ ④ 生成分类 XML，插进 3 个 toolbox；插入 script 标签
   │ ⑤ 改 maingui.js：两处条件注入
   ▼
重新打包 zfbRes_v1 → browser_assets（补丁）
   │ ⑥ 自检：条目数/顺序/新增集合/逐字节比对
   ▼
install：备份原版 → 原子替换 → 校验 sha → 失败回滚
```

> 安装分两段：**普通权限编译**（无头 Chrome 在管理员窗口里会失效），再 **UAC 安装**。
> 所以双击 `安装原生积木.cmd` 时，先看到一个普通权限的黑窗口编译，之后才弹 UAC。

## 7. 限制（务必知道）

1. **需要管理员权限**：改的是 `Program Files` 下的资源包；安装/还原都要 UAC 点「是」。
2. **安装前必须关闭 IDE**，否则资源文件被占用。
3. **每改一次函数库，必须重新安装一次**；新函数才会出现在 IDE 里。
4. **界面不能新建带参数的函数**（官方屏蔽了参数 mutator）；要从示例库复制带参函数再改名。
5. **函数名只能用英文/数字/下划线**，不能数字开头；改名会让旧工程里的旧块失效。
6. **软件升级/重装会覆盖资源包**，需要重新安装补丁；跨版本不要用旧备份还原新版本。
7. **用自定义块保存的工程，在未打补丁的电脑上打开会缺块**；换电脑要装同样的补丁。
8. **构建需要 Chrome 或 Edge + Python 3.8+**；没有浏览器/没有管理员权限，可以用便携版（复制一份软件到用户目录再打补丁）或离线包。
