## 2. 核心事实与引用（行号 = 相对工作区根目录）

### 2.1 PC 官方软件（AbilixScratch3.0）
- 编译按钮只做语法检查（PC 自带 Python 3.7.3）：`逆向资料/decompiled/Assembly-CSharp.decompiled.cs:92081`（compilerPath）、`:92097-92141`（`python.exe -m compileall code\main.py`）、`:120317-120331`（写 `code\main.py`）。
- 下载物是 `.py` 源码 zip（不是 pyc、不加密）：`逆向资料/下载分析/下载链路逆向.md:21`、`:27`、`:79-95`、`:133`。
- 机器型号编码：SKCON9=111=0x6F → `extenddatas/brainApk/6F/Controller_43.apk`；映射证据 `逆向资料/decompiled/Assembly-CSharp.decompiled.cs:116394`（`machineType:X`）+ `...standingwindows/hot_update_dir/extenddatas/brainApk/brainApkVersion.txt`。
- 有线下载走串口（LibUart），不是 ADB：`逆向资料/decompiled/Assembly-CSharp.decompiled.cs:95826-95890`、`逆向资料/下载分析/下载链路逆向.md:80`、`:473`。
- PC 自带 `adb.exe`（`StreamingAssets/adb/adb.exe`，908800 B）且常量 `COMPANDEXEC="adb.exe"`（`逆向资料/decompiled/Assembly-CSharp.decompiled.cs:110817-110819`），但 Assembly-CSharp 全文只有 3 处 `Process.Start`（92100 编译、100208 自升级、115811 自升级），**没有调用 adb** → 该 adb 在本版本可能未使用（推断）。
- UDP 发现/配网：PC 广播到 7777、本地收 9999，机器人回 160,255 + 自己的 IP：`逆向资料/decompiled/Assembly-CSharp.decompiled.cs:109990-110209`、`逆向资料/下载分析/协议规格.md:407-435`；官方软件此版本扫描链路疑似失效、实际靠手填 IP（`协议规格.md:424-432`）。
- 手册：硬件、双处理器、WiFi/热点、蓝牙仅硬件提及、我的程序、EEPROM：`_分析临时/SKCON9手册/SKCON9手册_全文.txt:133-148`、`:200-213`、`:381-384`、`:395-400`、`:466-515`、`:120-122`。

### 2.2 机器人端“大脑 app”：6F/Controller_43.apk
- 包名 `com.abilix.controller`，versionName 1.0.43，targetSdk 27，**无 `android:debuggable` 属性（默认 false，release）**：`_分析临时/apk分析/提取/manifest_Controller6F.xml:1-51`（apk-dex 用 androguard 解析的权威版本；本目录 `controller43_6F/manifest_parsed.txt` 为同口径复核）。
- 权限含 INTERNET/ACCESS_WIFI_STATE/CHANGE_WIFI_STATE/BLUETOOTH/BLUETOOTH_ADMIN/WRITE_EXTERNAL_STORAGE 等；`uses-feature android.hardware.bluetooth_le required=true`：同上 manifest 3-18 行。
- Python 执行链：`com/abilix/utils/ProgramAndInterfacePython`（`runPython(String)` → `PythonTask` 线程）：`_分析临时/apk分析/提取/disasm_C_com_abilix_utils_ProgramAndInterfacePython.txt:76-84`。
- Python 运行时路径：`/system/lib/python/libpython3.4m.so`、`/system/lib/python/python3.4.zip`、`/python_dir`、`initPythonEnv`、`DIR_PYTHON_DATA/LIB`、`getStarPython`、`runPythonFile`：`_分析临时/研究证据/运行环境/controller43_6F/dex_strings_all.txt:2299-2301,2321,2328-2330,6878-6879,38629,40147,50020-50021`。
- StarCore(srplab) 引擎为独立系统 App：`/data/data/com.srplab.starcore/lib/libstar_java.so`：同文件 `:2299-2301`。
- Python 程序模板（机器人端 Blockly 生成 Python 也用同一模板）：`#!/usr/bin/python3` + `import threading/import time/import libstarpy` + `robot = Robot()`：同文件 `:774-780`。
- 网络服务端在 Controller：`TCP_CMD_PORT_10086`、`TCP_TRANS_PORT_8890`、`UDP_LISTENING_PORT_7777`、`UDP_SENDING_PORT_9999`：同文件 `:25160,25174,26358-26359`（apk-dex 另有 `new TCPNettyServer(...)`/`new UDPNettyServer(7777,9999)` 构造证据，见其报告）。
- C 程序运行时：`System.loadLibrary("Robot")` + `libuser.so`：`_分析临时/apk分析/提取/scan_ctrl_loadlib.txt`（ProgramAndInterfaceC `<clinit>`）；apk-dex 进一步确认 `.c` 是机器人本机 gcc 编译成 `.so` 后 `JCC_Main` 执行（见其报告，本报告 §C5 引用）。
- 文件系统：写权限存在、程序目录 `/python_dir`、StarCore 临时目录 `/sdcard/srplab/tmp`、`programDir is Empty!`：dex_strings_all.txt `:2321-2322,2310-2311,48702`；具体 cwd/可写性待真机实测（探测程序地址 70-72）。
- 蓝牙：dex 里只有 `STREAM_BLUETOOTH_SCO` 等系统枚举；无用户 API（本报告 §C4）。

## 3. 待真机验证清单（按优先级）
1. `探测_import与环境.py`：socket/os/threading/subprocess 是否可 import；sys.version；本机 IP；cwd；EEPROM 结果。
2. 两板同路由器：各板 IP、互 ping（PC 上 `Test-NetConnection <IP> -Port 10086` 已知能测连通）、跑 TCP 样例。
3. 热点模式：A 板开热点 B 板连，A 板 IP 是否 192.168.43.1。
4. USB-C 接 PC：设备管理器出现的是 COM 口（USB 串口）还是 Android ADB Interface；`C:\platform-tools\adb.exe devices` 输出。
5. 机器人屏幕：设置→WLAN 是否显示本机 IP；EEPROM 页面能否查看探测结果。
