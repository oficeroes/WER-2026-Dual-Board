## classes

### class Robot | constructor=Robot() | platforms=['SKCON9', 'SKCON5']
doc: 控制器运行时自动注入的 Robot 类（SKCON9/SKCON5）。程序里写 robot = Robot() 创建对象，所有硬件 API 都调用 robot.xxx(...)。不要自己定义该类，也不要 from libstarpy import Robot 写进下载到控制器的代码。

- `set_motor(port: int, speed: float) -> None` ｜port:int, speed:float -> None
  doc: 设置单个电机的速度并保持。非阻塞：调用后立即返回，电机一直按该速度转，不会自动停；要停必须再调用 set_motor(port, 0)。同一端口后一次调用覆盖前一次速度。生成器会自动把速度 clamp 到 -100～100。
   - port: 电机端口 1～4（界面 A/B/C/D）
   - speed: 速度 -100～100（%），负=反转，0=停

- `set_motor_time(port: int, speed: float, seconds: float) -> None` ｜port:int, speed:float, seconds:float -> None
  doc: 单个电机按指定速度转 N 秒后自动停。是否阻塞【推断/待实测】：手册与生成器未明确，多数资料推断为“转完才返回”；若发现后续动作“抢跑”，说明该固件下可能非阻塞，需要自己补等待。常用于抬臂、夹爪、推杆等按时间动作的机构。
   - port: 电机端口 1～4
   - speed: 速度 -100～100（%）
   - seconds: 持续时间（秒），生成器 clamp 到 0～3600

- `set_motor_encoder(port: int, speed: float, target: float) -> None` ｜port:int, speed:float, target:float -> None
  doc: 单个电机转动，直到编码器读数超过目标值后停。阻塞【推断】。使用前建议先 reset_encoder，否则目标是从上电累计值算起。反向运动时 target 正负/比较方式取决于固件，需实测。
   - port: 电机端口 1～4
   - speed: 速度 -100～100（%）
   - target: 目标编码器计数，生成器 clamp 到 -99999～99999

- `set_double_motor_time(port_a: int, speed_a: float, port_b: int, speed_b: float, seconds: float) -> None` ｜port_a:int, speed_a:float, port_b:int, speed_b:float, seconds:float -> None
  doc: 两个电机同时按各自速度转 N 秒后停（双轮定时/双机构同步）。阻塞【推断】。两轮同向正转=前进；想原地转，一轮正一轮负。参数顺序由生成器证据确定（channel_1, speed_1, channel_2, speed_2, time）。
   - port_a: 第一个电机端口 1～4
   - speed_a: 第一个电机速度 -100～100
   - port_b: 第二个电机端口 1～4
   - speed_b: 第二个电机速度 -100～100
   - seconds: 持续时间（秒），clamp 到 0～3600

- `set_double_motor_encoder(port_a: int, speed_a: float, port_b: int, speed_b: float, encoder_port: int, target: float) -> None` ｜port_a:int, speed_a:float, port_b:int, speed_b:float, encoder_port:int, target:float -> None
  doc: 两个电机同时转，直到指定的那个编码器通道读数超过目标值后停（双轮定量直行常用：用 A 轮里程作参考、B 轮跟着转）。阻塞【推断】。参数顺序由生成器证据确定（channel_1, speed_1, channel_2, speed_2, channel_3, angle）。Robot.h 中无同名 C 函数，属 Python 层封装。
   - port_a: 第一个电机端口 1～4
   - speed_a: 第一个电机速度 -100～100
   - port_b: 第二个电机端口 1～4
   - speed_b: 第二个电机速度 -100～100
   - encoder_port: 以哪个电机的编码器为准（1～4）
   - target: 目标编码器计数，clamp 到 -99999～99999

  doc: 电机高级设置（更换电机类型、逻辑反转、开环/闭环）。非阻塞的“配置”类命令，一般在上电初始化时设一次。reverse 通常保持 0，方向统一在代码里用方向常数处理，避免双重反转。配置是否掉电保存待实测。
   - port: 电机端口 1～4

   - channel: 智能电机 ID 1～11（254=全部）

   - port: 数字输出端口 1～12
   - state: 状态：0=OFF/释放/灭，1=ON/吸合/亮

- `get_encoder(port: int) -> int` ｜port:int -> int
  doc: 读取电机编码器累计计数（可被 reset_encoder 清零）。用来算位移、速度、双轮同步纠偏。编码器通道号默认等于电机端口号，但接线不同时可能不同，建议在配置区显式写 LEFT_ENC/RIGHT_ENC。
   - port: 编码器/电机通道 1～4（A～D）

- `reset_encoder(port: int) -> None` ｜port:int -> None
  doc: 把电机编码器累计值清零。建议习惯：任何需要计数的动作前先清零，否则读到的是上电以来的累计值。
   - port: 编码器/电机通道 1～4

- `get_instant_incoder(port: int) -> int` ｜port:int -> int
  doc: 读取编码器“实时值”。注意：SKCON9/SKCON5 的方法名拼写是 incoder（少一个 e），写 get_instant_encoder 会找不到方法。与 get_encoder 的区别【待实测】：累计值用于位移控制，实时值更像瞬时读数，不要用它做累计位移。
   - port: 编码器/电机通道 1～4

- `get_instant_encoder(port: int) -> int` ｜port:int -> int
  doc: 读取编码器“实时值”（SKCON2 的拼写）。注意：SKCON9/SKCON5 上不存在这个方法，那两个型号要用 get_instant_incoder（拼写不同）。
   - port: 编码器/电机通道 1～4
