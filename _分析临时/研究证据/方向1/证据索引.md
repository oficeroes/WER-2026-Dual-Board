# 方向1 证据索引（hw-port）

本目录是方向1 的证据与可复跑脚本目录。主报告：`双板通讯研究/分报告_方向1_端口与内存.md`。

## 文件清单

| 文件 | 内容 |
|---|---|
| `scan_apk.py` / `apk_scan.txt` | 解包 `BlocklyC_V103.apk`（本机侧 App），提取 classes.dex / libserial_port.so / 布局 / AndroidManifest，扫描端口、串口、EEPROM 相关字符串 |
| `scan_apk2.py` / `apk_scan2.txt` | 从 dex 中提取协议类字符串（CMD1_*/CMD2_*/CMD_BOOT/CRC/"包头出错"等） |
| `scan_apk3.py` / `apk_scan3.txt` | dex 中文串（"包头出错:/校验位出错:/类型出错:/灰度N:/碰撞N:/端口N:"）+ 方法名（getrAI0..7/getsDO/UpdateStm32/EepromActivity 等） |
| `BlocklyC_V103_apk/` | 解包出的 classes.dex、libserial_port.so、activity_*.xml（二进制 AXML）、device_filter.xml |
| `电气测量记录表.md` | 两板对接前的万用表/示波器逐项测量表（现场填写用） |

## 关键原始证据摘录（出处见主报告 §7）

1. **端口=STM32 管理的传感器口**：`BlocklyC_V103.apk` dex 内 `SerialProcess`/`SerialPort`/`org/winplus/serial/utils/SerialPort`、`initSerialPort successful!`、`nPort/nSpeed/baudrate`；协议命令 `CMD1_0..CMD1_4`、`CMD1_A0`、`CMD1_A1`、`CMD2_0..CMD2_4`、`CMD_BOOT`、`CMD_ONE`、`CMD_RESET`；错误串"包头出错:/校验位出错:/类型出错:"；`/Download/Blockly/update/stm32.bin`。
2. **端口读数/输出经板内命令**：dex 方法名 `getrAI0..7`、`getrAII0..7`、`getsDO`、`getsCmd`、`getrCmd`、`UpdateStm32`；中文 UI 标签 "端口1:"…"端口7:"、"碰撞1:"…、"灰度1:"…。
3. **读写数据 UI 在本机**：`EepromActivity`/`activity_eeprom`/`'robot.getEE'`/`'robot.setEE'`/`'EEPROM'`；布局为 GridView 列表。
4. **端口自动识别**：SKCON9 手册 p11（`_分析临时/SKCON9手册/SKCON9手册_全文.txt:234-236`）；SKCON5 手册 `:218-220`。
5. **EE 三层限制不一致**：Scratch 积木 1~128 + clamp ±99999；Chart 3.0 UI 地址 1~40、值 0~4095（`逆向资料/xlua明文/ui/pc_chart/chart_tips/chartReadWriteDataTipsView.lua:121-140`）；C API 无边界文档。
6. **C API 是"命令字符串→Java 桥"**：`_分析临时/stm32分析/02_syms_strings.txt:190-231` 的"方法名+格式串"表 + `CCJ_Interface`（`01_elf_info.txt:46`）；`05_disasm_annot.txt:653-761` 的 JNI 调用模式。
7. **轮询节奏**：`逆向资料/样本程序/main.py:143-146`（`while not get_touch(5): … time.sleep(0.01)`）；规范要求轮询加 0.01~0.05s（`WER机器人代码生成_给AI的说明书.md:435`）。
8. **adb 线索**：`逆向资料/decompiled/Assembly-CSharp.decompiled.cs:110819` 定义 `COMMANDEXEC="adb.exe"`，全仓库无反编译调用点（仅 `asmcs_ascii.txt:5268` 同串）→ 遗留常量，不能证明官方 adb 通道。
9. **PC 端不碰 EE**：C# 反编译全文中 `EEPROM|Eeprom|SetEE|GetEE` **零命中**。

## 复跑方法

```powershell
# 在仓库根目录执行（需要 python 3）
python _分析临时\研究证据\方向1\scan_apk.py
python _分析临时\研究证据\方向1\scan_apk2.py
python _分析临时\研究证据\方向1\scan_apk3.py
```

> 说明：APK 路径硬编码为 `D:\Program Files\AbilixScratch3.0\...\BlocklyC_V103.apk`；这是 PC 软件 `Constants.UPDATEPATH` 指向的本机侧 App（`Assembly-CSharp.decompiled.cs:110829-110831`）。
