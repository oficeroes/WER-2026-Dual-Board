# APK 解包目录未收录

本目录原本约 **61 MB**，包含机器人端 APK 的 dex 反汇编、`libRobot.so`、
`stm32.bin`、manifest 解码等二进制/中间产物。

出于版权与仓库体积考虑，这些内容没有进入 GitHub。相关结论已经写在：

- `双板通讯研究/分报告_APK与串口协议.md`
- `双板通讯研究/分报告_STM32固件与串口协议.md`
- `_分析临时/研究证据/`（文本日志/证据）
- `_分析临时/stm32分析/`（固件反汇编文本）

需要原始文件时，请在自己安装的 `AbilixScratch3.0 1.0.3.4` 的 `StreamingAssets`
里找到 `brainApk`，重新解包。
