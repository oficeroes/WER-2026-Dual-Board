# WER 函数库：打开积木编程，左侧就有「我的函数」

> **GitHub 版说明**：本仓库不带 85 MB 的 `browser_assets.patched` 和原版备份；
> 安装/还原请按 [`docs/04_安装步骤.md`](../docs/04_安装步骤.md) 在本机生成补丁。
> 安装前会先编译「我的函数」，再生成「双板通讯」补丁。

> **一句话**：给这台电脑上的 AbilixScratch3.0 打一个补丁，左侧分类栏就多出一个紫色「我的函数」分类；把里面的函数块拖进程序，右侧 Python 面板会自动带上函数定义。
>
> 读者：带队老师 / 参赛学生（不需要会写代码，只需要会双击文件）。
> 适用：WER 2026 普及赛 · Windows · 本机已安装 AbilixScratch3.0（1.0.3.4）。

---

## 1. 先看：做完之后是什么样

- 打开「积木编程」→ 左侧分类栏最下面多出一个**紫色**分类「**我的函数**」。
- 点开它，里面一排函数积木：`func_Init`、`func_Stop`、`func_ForwardCM`……
- 把 `func_ForwardCM` 拖到主程序里，参数槽填 `40`，接到 `start` 后面。
- 右侧 Python 面板自动生成：

```python
def func_ForwardCM(cm):
    robot.set_double_motor_time(1, clamp(var_speed), 2, clamp(var_speed), clamp(cm / var_1cm * 1000, -3600, 3600))
    ...
```

并且程序里会调用 `func_ForwardCM(40)`。**不用在项目之间复制粘贴函数定义。**

> 原理一句话：函数定义被编译进 IDE 自己的资源包里，IDE 认为这些积木是它天生就有的（详见 [01_原理与改动点.md](修改软件说明/01_原理与改动点.md)）。

## 2. 3 分钟上手（第一次安装）

### 第 1 步：关掉 AbilixScratch3.0

安装要替换软件的资源文件，**IDE 必须完全关闭**（包括后台窗口）。没关会提示「IDE 正在运行」，关掉再试即可。

### 第 2 步：双击安装

打开文件夹 `WER_函数库\工具\原生积木\`，双击：

```
安装原生积木.cmd
```

1. 第一个黑窗口先做**编译**（普通权限，**不弹 UAC、不用点任何东西**）：解包约 80 MB 资源、调用真实积木引擎生成函数定义，大约 **10～30 秒**。
2. 编译完成后**才弹出 UAC 权限窗口**（"你要允许此应用对你的设备进行更改吗？"）→ 点「**是**」。
   - **不点「是」= 什么都不会装**。这是第一次使用最常见的失败原因。
   - **请直接双击运行，不要右键「以管理员身份运行」**：管理员窗口里浏览器引擎无法运行，会导致编译失败。新版脚本已自动分「普通权限编译 → UAC 安装」两段，不需要你手动切换。
3. 看到这些字就是成功了：

```
...
安装完成 ✔
  资源包：D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets
  大小  ：81.3 MB（增加 3.9 KB）
  sha256：…
  函数  ：1 个（func_Hello）
打开 IDE → 左侧「我的函数」分类 → 拖积木。
...
[DONE] Native blocks are installed. Open AbilixScratch3.0 and look for the "My Functions" category.
```

4. 最后窗口会停住并提示「按任意键继续」，**按任意键**关闭即可（这是故意停住的，方便你看结果）。

> 安装前会自动备份原始资源包到 `WER_函数库\工具\原生积木\备份\`，出问题可以一键还原（见第 5 节）。

### 第 3 步：打开 IDE，新建或打开一个项目

打开 AbilixScratch3.0 → 积木编程 → 新建项目（或打开已有项目）。
左侧分类栏底部应该出现紫色「**我的函数**」。

### 第 4 步：拖函数块进程序

点「我的函数」→ 把需要的函数块拖到中间工作区，接到 `start` 后面（和普通积木一样拼接）。
带参数的函数（如 `func_ForwardCM`）参数槽里填数字即可。

### 第 5 步：看右侧 Python

点右侧「Python」面板（或切换代码视图），应该能看到：

1. 程序开头有一段 `def func_xxx(...): ...`（来自函数库，自动注入）；
2. `main()` 里出现你拖的调用，比如 `func_ForwardCM(40)`。

**到这一步就成功了。** 你可以在 [示例/WER函数库.srhs](示例/WER函数库.srhs) 里看到 20 个现成函数的用法与参数说明（文件 → 打开即可，不要保存覆盖）。

## 3. 常见问题（先查这里）

| 现象 | 原因 / 解决 |
| --- | --- |
| 双击后窗口一闪而过，好像什么都没发生 | 没点 UAC 的「是」。重新双击，**看清 UAC 窗口点「是」**。 |
| 黑窗口里出现 `[NOT APPLIED] Administrator rights were not granted.` | 同上：UAC 被拒绝。可右键 `安装原生积木.cmd` →「以管理员身份运行」。 |
| 安装完打开 IDE，左侧**没有**「我的函数」 | ① 安装没成功（回到上一步看输出）；② 安装时 IDE 没关，或安装后 IDE 没重启；③ 打开的是别的软件/别的版本。关掉 IDE 重开，再不行跑一次 `状态检查.cmd`（见下）。 |
| 有「我的函数」分类，但拖进程序后右侧 Python 没有 `def` | 拖的块要真的接在主程序链里（已连接到 `start`）；空放着不生成。也可能是旧项目缓存，保存后重开项目。 |
| 改了 `我的函数库.srhs`，但 IDE 里还是旧函数 | **每改一次函数库都要重新安装一次**（第 6 节）。改完保存 → 关 IDE → 再双击 `安装原生积木.cmd`。 |
| 提示「IDE 正在运行」 | 关掉 AbilixScratch3.0（任务管理器里确认没有 `AbilixScratch3.0.exe`）再安装。 |
| 提示「需要管理员权限」 | 从 `安装原生积木.cmd` 双击运行；或右键 →「以管理员身份运行」。 |
| 提示需要 Chrome 或 Edge / 真实引擎生成失败 | 编译阶段需要这台电脑装有 **Chrome 或 Edge**（用真实浏览器引擎跑 IDE 自己的积木代码生成函数定义）。装上浏览器后重试；没有浏览器就用离线包。 |
| 黑窗口里出现 `真实引擎生成函数库 Python 失败（退出码 3）` 或 `harness 未返回有效结果` | 旧版安装脚本把编译放在管理员窗口里跑，提权后浏览器引擎会失效（本机 Chrome 157 实测）。新版 `安装原生积木.cmd` 已改成「先普通权限编译 → 再弹 UAC 安装」，重新双击即可。也可以直接用离线包 `安装包\安装原生积木(离线).cmd`（不需要浏览器和 Python）。 |
| 提示「这不像本机记录的原始资源包（sha256 不同）」但继续成功 | 你的软件版本/资源包与开发机不完全一致。工具仍会打补丁，但**请先做备份**；如果 IDE 异常，用 `还原原版.cmd` 回到安装前状态。 |
| 杀毒软件报警 / 文件被锁 | 把 `WER_函数库` 加入信任；确认 IDE 已关闭后重试。 |
| 想检查现在到底装没装 / 函数库是不是最新的 | 双击 `工具\原生积木\状态检查.cmd`（不需要管理员），看「原生积木：已打补丁 / 是否需要重装」。 |
| 想彻底恢复原版软件 | 双击 `工具\原生积木\还原原版.cmd` → UAC 点「是」（见第 5 节）。 |
| 旧工程打开后函数块变成灰色/未知块 | 安装补丁前保存的工程里没有原生块；若工程里**曾拖入**原生函数块，换到**没打补丁的电脑**打开就会变成未知块。见第 7 节限制。 |
| 换过函数库后，打开旧工程整个积木区变灰、新建项目却正常 | 旧工程里用到了**新函数库中已删除/改名**的函数块。把旧函数加回 `我的函数库.srhs` 后重装，或改在新建项目里重新拖块；旧工程里的旧块无法自动迁移。 |

## 4. 我要自己加函数 / 改函数（进阶）

函数库就是普通项目文件：`WER_函数库\我的函数库.srhs`。做法：

1. 打开 AbilixScratch3.0 → 积木编程 → 文件 → 打开 → 选 `WER_函数库\我的函数库.srhs`。
2. 左侧「函数」分类 → 拖「**新建函数**」到工作区 → 把名字改成 `func_你的名字`（英文/数字/下划线，不能数字开头）→ 在函数体里搭积木。
3. 按 `Ctrl+S` 保存（覆盖原文件，路径不要变）。
4. 关闭 IDE → 双击 `工具\原生积木\安装原生积木.cmd` → UAC 点「是」→ 重新打开 IDE 就生效。

**关于带参数的函数（重要）**：
官方这版 IDE 把界面上「编辑函数参数」的功能屏蔽了，所以**界面里新建不出带参数的函数**。需要带参数时：

1. 打开示例库 `WER_函数库\示例\WER函数库.srhs`（文件 → 打开）；
2. 在函数定义区找到类似的带参函数（例如 `func_ForwardCM(cm)`），**右键 → 复制**；
3. 回到 `我的函数库.srhs` 的工作区，**右键 → 粘贴**；
4. 改函数名（参数名和参数个数保留示例的即可）。

**注意**：
- 函数名只能用英文字母、数字、下划线，且不能以数字开头（如 `func_ForwardCM2`）；中文名会在安装时报错。
- 函数名不能重复；参数名也要是英文。
- **改了函数名 = 旧工程里的旧积木会失效**（旧块找不到对应积木）。改名后旧工程需要重新拖一次块。
- 参数名会同时出现在工程的变量列表里（这是 IDE 的正常行为，无害）。
- 函数暂时不支持返回值。

## 5. 还原原版（撤销安装）

1. 关闭 AbilixScratch3.0；
2. 双击 `WER_函数库\工具\原生积木\还原原版.cmd`；
3. UAC 点「是」；
4. 看到 `还原完成 ✔`（资源包 sha256 与本机记录一致）即恢复成安装前的资源包（用安装时自动备份的那份）。

还原后「我的函数」分类会消失；工程文件本身不受影响（但工程里已拖入的原生函数块会变成未知块，见第 7 节）。

安装时自动备份的原始资源包在：

```
WER_函数库\工具\原生积木\备份\browser_assets.原始.<sha前12位>.bin
```

**这个备份别删**——重装、还原、软件升级后重打都要用它。详见 [04_回滚与升级重打.md](修改软件说明/04_回滚与升级重打.md)。

## 6. 改了函数库之后（更新）

每次修改 `我的函数库.srhs` 后，都要**重新安装一次**：

1. 关闭 IDE；
2. 双击 `安装原生积木.cmd` → UAC 点「是」；
3. 重新打开 IDE。

工具会自动用「安装前备份的原始资源包 + 当前函数库」重新编译，不需要先还原。装完可以双击 `状态检查.cmd` 确认「是否需要重装：否（已同步）」。

## 7. 限制与注意事项（务必读一遍）

1. **需要管理员权限**：安装/还原都要 UAC 点「是」。普通权限双击 = 什么都不改。
2. **安装前必须关闭 IDE**：否则资源文件被占用，工具会拒绝执行（防止装坏）。
3. **每改一次函数库，必须重新安装一次**，新函数才会出现在 IDE 里。
4. **改函数名会让旧工程里的旧积木失效**（积木类型与函数名绑定）。改名后旧工程要重新拖块。
5. **界面不能新建带参函数**：从 `示例\WER函数库.srhs` 复制带参函数再改名。
6. **软件升级/重装会覆盖资源包**：升级后需要重新安装一次（备份与升级的注意事项见 04 文档）。
7. **安装要求**：这台电脑需要 Python 3.8+（建议 3.12）以及 Chrome 或 Edge（生成函数定义用）。`安装原生积木.cmd` 会自动找 Python。
8. **只改软件资源包，不改你的工程文件**：`.srh` / `.srhs` 工程格式不变；但用原生函数块保存的工程在**未打补丁的电脑**上打开会缺块。要给别的电脑用工程，那台电脑也要装同样的补丁，或者只用普通积木。
9. **同一台电脑换系统/换安装路径**：工具按默认路径找软件；装到别处时可在命令行用 `--assets` 指定（见 [工具/原生积木/说明.md](工具/原生积木/说明.md)）。
10. **本机开发说明**：本工具按 `AbilixScratch3.0 1.0.3.4` 的资源包校验（sha256 见 03/05 文档）。版本不同会给出警告，必要时先备份再操作。
