# 便携版工具说明（原生函数积木方案）

本目录是 **「原生函数积木」方案的免管理员便携版工具**。

一句话：把本机安装的 `AbilixScratch3.0` **复制**到用户自己可写的纯 ASCII 目录，
再用核心工具把「**我的函数库**」编译成 IDE **原生积木**写进副本资源包。
之后启动的是便携副本，左侧会出现紫色 **「我的函数」** 分类，里面的函数块可以像
普通积木一样拖进任何项目，右侧 Python 里自动生成 `def func_xxx()` 定义与调用。

> **不需要管理员权限、不修改安装目录、随时可以一键删除。**
> 与上一轮「模板注入」方案的区别：不再往「新建项目」模板里塞积木，
> 而是把函数变成 IDE 真正认识的原生积木分类（可拖拽、有 Python 代码生成）。

---

## 一、一分钟上手

```bat
:: 1) 创建便携副本（双击 .cmd 更好；第一次约 1~2 分钟）
python 创建便携函数版.py

:: 2) 以后改了「我的函数库」后更新（先关掉便携版 IDE）
python 更新便携函数版.py

:: 3) 不用了，删除（默认只预览，加 --yes 才真删）
python 删除便携版.py --yes
```

创建完成后：

1. 双击桌面快捷方式 **「AbilixScratch3.0 函数版」**（或
   `%USERPROFILE%\AbilixScratch3.0_FuncLib\AbilixScratch3.0.exe`）启动；
2. 左侧分类栏点 **「我的函数」**（紫色图标），即可把函数块拖进工作区；
3. 想换函数：在正常 IDE 里编辑函数并保存为 `WER_函数库\我的函数库.srhs`，
   运行一次 `更新便携函数版.py`，重启便携版即可。

> 本目录所有 `.cmd` 都是**纯 ASCII 薄封装**：双击即可，会自动找 Python 3.8+；
> 中文脚本名通过 Unicode 转义加载，命令行参数原样转发给 Python。
> 也可以直接在命令行 `python 创建便携函数版.py --help` 看全部参数。

## 二、文件说明

| 文件 | 作用 |
| --- | --- |
| `创建便携函数版.py` / `.cmd` | **创建**便携副本：复制安装目录 → 备份副本内原始资源 → 核心工具 build 生成原生积木版资源 → 桌面快捷方式 |
| `更新便携函数版.py` / `.cmd` | **更新**：用最新「我的函数库」从副本内原始资源重新构建，原子替换；不累积副作用 |
| `删除便携版.py` / `.cmd` | **删除**：安全删除便携副本 + 桌面快捷方式（默认 dry-run，`--yes` 才真删） |
| `原生便携版公共.py` | 三个入口共用的底层模块（复制/快捷方式注册表保护/构建封装/安全校验） |
| `便携版公共.py` | 通用能力底层（安装目录定位、硬链接复制、快捷方式、注册表保护、AppData 备份等）；随本目录一起打包，**整个 `便携版/` 目录单独拷到别的电脑也能用** |
| `说明.md` | 本文件 |

### 便携副本的目录结构

```
C:\Users\<用户>\AbilixScratch3.0_FuncLib\        ← 默认副本目录（纯 ASCII，可改）
├─ AbilixScratch3.0.exe                          ← 启动这个（桌面快捷方式指向它）
├─ AbilixScratch3.0_Data\
│  └─ Resources\browser_assets                   ← ★ 已编译进「我的函数」原生积木
├─ _原始资源\
│  ├─ browser_assets.orig                        ← 安装目录原版资源包备份（更新用）
│  └─ browser_assets.上一版                      ← 上一次构建出的资源包（可选，回滚用）
└─ ...（其余文件从安装目录复制而来）
```

## 三、三个脚本的详细用法

### 1. 创建：`创建便携函数版.py`

| 参数 | 说明 |
| --- | --- |
| `--source 目录` | 软件安装目录（默认自动探测 `D:\Program Files\AbilixScratch3.0`） |
| `--target 目录` | 便携副本输出目录（默认 `%USERPROFILE%\AbilixScratch3.0_FuncLib`；**必须纯 ASCII**） |
| `--library 文件` | 函数库源 `我的函数库.srh/.srhs`（默认自动找；都已存在时优先 `.srh`） |
| `--shortcut-name 名字` | 桌面快捷方式文件名（默认 `AbilixScratch3.0 函数版.lnk`，快捷方式名可以含中文） |
| `--no-shortcut` | 不创建桌面快捷方式 |
| `--no-build` | 只复制不构建（调试用，副本还是原版软件） |
| `--force` | 目标已存在时删除重建（默认报错，避免误删） |
| `--allow-non-ascii` | 允许非 ASCII 路径（**不建议**，见常见问题） |
| `--no-fix-registry` / `--no-appdata-backup` | 不处理 / 不备份 AppData 安全开关（不建议） |
| `--report 文件` | 把完整 JSON 报告写到指定路径（留证据） |
| `--verbose` | 打印每个文件的复制方式（硬链接 / 独立复制 / 回退） |

命令示例：

```bat
python 创建便携函数版.py
python 创建便携函数版.py --target "D:\AbilixScratch3.0_FuncLib"
python 创建便携函数版.py --library "WER_函数库\我的函数库.srhs" --report "WER_函数库\证据\创建报告.json"
```

### 2. 更新：`更新便携函数版.py`

| 参数 | 说明 |
| --- | --- |
| `--target 目录` | 便携副本目录（默认同上） |
| `--library 文件` | 函数库源（默认自动找 `我的函数库.srh/.srhs`） |
| `--dry-run` | 只检查状态、不构建 |
| `--verify-only` | 只校验当前副本资源，不重新构建 |
| `--adopt-orig` | 副本缺 `_原始资源\browser_assets.orig` 时，若当前资源仍是原包则自动采纳 |
| `--no-keep-prev` | 不保留上一版资源包 |
| `--report 文件` | 写 JSON 报告 |

命令示例：

```bat
python 更新便携函数版.py
python 更新便携函数版.py --dry-run
python 更新便携函数版.py --verify-only
```

### 3. 删除：`删除便携版.py`

| 参数 | 说明 |
| --- | --- |
| `--target 目录` | 便携副本目录（默认同上） |
| `--yes` | **真的执行删除**（默认只预览会删什么） |
| `--keep-shortcut` | 保留桌面快捷方式 |
| `--force` | 目录名不像便携副本时也允许删（谨慎） |
| `--report 文件` | 写 JSON 报告 |

命令示例：

```bat
python 删除便携版.py
python 删除便携版.py --yes
```

## 四、原理与安全设计

### 1. 为什么能免管理员

- 便携副本完全在**用户可写目录**（默认 `%USERPROFILE%`），不碰
  `D:\Program Files\AbilixScratch3.0`，因此不需要 UAC、也不需要管理员账号；
- 普通文件复制时优先 `os.link` **硬链接**（同盘 NTFS 几乎不占空间），跨盘/失败自动
  回退为真实复制；
- **`browser_assets` 永远强制独立复制**——绝不能用硬链接：构建时资源包会被整体替换，
  若是硬链接会直接改坏安装目录。复制后还会用 `os.path.samefile` 校验资源包已独立。

### 2. 资源包构建流程（核心安全点）

```
副本 browser_assets（原版副本）
   → 移入 _原始资源\browser_assets.orig（备份，只此一份）
   → 核心工具 build：orig + 我的函数库 → 新资源包（先写临时文件 browser_assets.build-<时间>）
   → 体积/sha 校验 > 用 verify 子命令确认只改了预期条目
   → 校验通过才 os.replace 原子替换副本 browser_assets；失败则副本原样不动、可无限重试
```

- 更新时**永远从 `browser_assets.orig` 重新构建**，所以反复更新不会累积补丁、不会越改越歪；
- 构建失败/中断时副本资源包不会被替换成半成品；
- 每次构建后都复核真实安装目录资源包 sha256 未变（只读校验，从不写安装目录）。

### 3. 处理「清空数据」一次性开关（保护已有项目列表）

软件安装后首次启动前，注册表 `HKCU\Software\partnerx\AbilixScratch3.0\` 里的
`clear_app_data_switch_h*` 若为 `1`（或缺失，软件默认按 1 处理），**下一次启动会清空**
`%USERPROFILE%\AppData\LocalLow\partnerx\AbilixScratch3_0\standalonewindows`
（含 `AbilixProjects` 全部作品列表），随后把开关置 0。

工具在创建前会检查该开关：**若为 1 → 先把 `AbilixProjects` 备份到目标副本旁
`AbilixProjects.备份-<时间戳>-原生积木便携版\`，再把开关置 0**，然后才复制/构建。

### 4. 目标路径必须纯 ASCII

实测（上一轮真机端到端验证）：便携副本路径含中文时，IDE 能启动，但内嵌 CEF
浏览器初始化失败 → **积木网页区全白**。所以默认目录名是
`AbilixScratch3.0_FuncLib`；`--target` 含非 ASCII 字符时工具会拒绝（除非
`--allow-non-ascii`）。桌面快捷方式的名字可以含中文（`函数版.lnk`），不影响。

### 5. 删除的安全设计

- 默认 **dry-run**，加 `--yes` 才真删；
- 删除前校验：目录里必须有 `AbilixScratch3.0.exe`；不能是安装目录、不能在
  Program Files 下、不能是盘符根/用户目录/桌面/工具目录；便携副本正在运行时拒绝删；
- 先改名成 `<目标>.删除中-<时间戳>` 再递归删除，避免删一半留下残骸；
- 只删副本 + 快捷方式：**不动**安装目录、AppData 项目列表、函数库源文件和工具本身。

## 五、常见问题（FAQ）

**Q1：双击创建后，左侧没有「我的函数」分类 / 积木区全白？**
- 先确认启动的是**桌面快捷方式指向的副本**，不是安装版；
- 确认 `AbilixScratch3.0_Data\Resources\browser_assets` 约 81 MB（被构建过）且
  `_原始资源\browser_assets.orig` 存在；
- 全白基本都是路径含中文/非 ASCII 引起，换纯 ASCII 路径重建；
- 仍不行运行 `python 更新便携函数版.py --verify-only` 看核心工具校验输出。

**Q2：「我的函数」分类是空的？**
函数库源里还没有函数（`procedures_defnoreturn` 数量为 0）。先在 IDE 里建好函数，
保存为 `WER_函数库\我的函数库.srhs`，再运行 `更新便携函数版.py`。

**Q3：更新时报「便携副本正在运行」？**
先完全退出便携版 IDE（确认任务管理器里没有 AbilixScratch3.0.exe），再更新。

**Q4：更新/构建失败怎么办？**
副本原样保留，可直接重试。看错误信息；常见是磁盘空间不足或在构建时被杀毒软件拦截。
实在不行 `python 创建便携函数版.py --force` 重建。

**Q5：想恢复成原版资源包？**
把 `_原始资源\browser_assets.orig` 复制回
`AbilixScratch3.0_Data\Resources\browser_assets`，或直接重建副本。

**Q6：便携版和安装版能同时开吗？**
不建议：两者共用同一份 AppData 项目列表，同时运行可能互相覆盖作品文件。

**Q7：怎么彻底卸载？**
`python 删除便携版.py --yes` 删除副本和快捷方式；AppData 项目列表本来就不属于
便携版，不会删除（如需备份在创建时已有可选的备份目录）。函数库源文件保留。

**Q8：换电脑/换安装路径能用吗？**
可以：整个 `WER_函数库` 目录拷到任意位置，工具按自身相对路径找核心工具；
`--source` 指定新安装目录即可。目标目录盘不够大时用 `--target` 指到大盘（必须纯 ASCII）。

## 六、依赖与限制

- Windows 10/11 x64 + Python 3.8+；
- 依赖核心工具 `../原生积木核心.py` 的 `build`/`verify`/`status` 子命令
  （本工具按 `--help` 自动探测参数名，核心工具小改不会失效）；创建/更新前会检查
  核心工具是否存在，不存在会给出提示（删除逻辑不依赖它）；
- 只适用于本机**已安装**的 AbilixScratch3.0（默认 `D:\Program Files\AbilixScratch3.0`，
  也可 `--source` 指定）；
- 构建需要临时磁盘空间：约「资源包大小 × 4 + 256 MB」；
- 复制优先硬链接：安装目录与目标目录**同盘**时几乎不占空间，跨盘时等于完整复制
  （约 400+ MB）。
