如何重新生成。**普通用户安装时完全用不到本目录**（安装包自带预编译产物，不需要 Python/Chrome）。

## 1. 重新编译（需要 Python 3 + Chrome 的电脑）

前提：本机要能读到**原版** resources 文件；建议先把真实安装目录拷一份到可写目录，
或者直接只读读取真实安装目录（build 只读源文件，不修改它）。

```bat
python "D:\UserData\Documents\WER\2026普级赛\WER_函数库\工具\原生积木\原生积木核心.py" build ^
  --library        "D:\UserData\Documents\WER\2026普级赛\WER_函数库\我的函数库.srhs" ^
  --source-assets  "D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets" ^
  --out            "D:\UserData\Documents\WER\2026普级赛\WER_函数库\安装包\browser_assets.patched" ^
  --workdir        "D:\UserData\Documents\WER\2026普级赛\_分析临时\offline_work\build" ^
  --prelude-out    "D:\UserData\Documents\WER\2026普级赛\WER_函数库\安装包\prelude.py" ^
  --json-out       "D:\UserData\Documents\WER\2026普级赛\_分析临时\offline_work\build_report.json"
```

说明：

- `--source-assets` 必须是**原版**资源包（已打过补丁的包会被 build 拒绝）。
- `--workdir` 会被清空重建；编译结束后可删除。
- build 内部会启动 Chrome + 真实 Blockly 引擎提取函数库 Python 前奏，约 8–60 秒。
- 成功后把 `build_report.json` 拷回本目录存档。

## 2. 重新生成 `WER_函数库/安装包/编译信息.txt`

编译信息由 `build_report.json` + `prelude.py` + 补丁包 zfb 索引共同整理，脚本为本目录的
`gen_build_info.py`（路径按本机调整）。**必须用 zfb 索引读取新增条目大小**：

```
/Blockly_Code/abilix_userlib.js   offset=85272115  length=1514
/Blockly_Code/abilix_userlib.json offset=85273629  length=1313
```

原因：补丁包内 manifest 的 `entries` 只记录 `maingui.html` / `maingui.js` / `abilix_userlib.js`
三项（它无法记录 manifest 自身的大小/sha），所以 `abilix_userlib.json` 的 1313 字节 / sha256
`972A301BD79769DFE514CA5E88CC2F68F32CDB2F6AA199A0B7E6E48DA3D7F058` 只能从包内条目实测。
（历史教训：早期版本生成脚本用 `entries[name] else 0` 回退，误写成「0 字节」，已修正。）

```bat
python "D:\UserData\Documents\WER\2026普级赛\WER_函数库\工具\原生积木\离线安装包\gen_build_info.py"
```

`编译信息.txt` 用 UTF-8 BOM + CRLF 写出（记事本/PS 5.1 都能正确读中文）。安装/还原脚本从中读取：

- `补丁包sha256` / `补丁包大小`（安装后校验用）
- `函数库sha256` / `函数列表`（显示与记录用）
- `原版资源包sha256` / `原版资源包大小`（还原时交叉校验用）

## 3. 重新自测（务必不要动真实安装目录）

```bat
copy /y "D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets" ^
        "C:\Users\<你>\AppData\Local\Temp\wer_offline_test\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets"

powershell -NoProfile -ExecutionPolicy Bypass -File "...\WER_函数库\安装包\安装.ps1" -Target "C:\Users\<你>\AppData\Local\Temp\wer_offline_test\AbilixScratch3.0" -Yes
powershell -NoProfile -ExecutionPolicy Bypass -File "...\WER_函数库\安装包\还原.ps1" -Target "C:\Users\<你>\AppData\Local\Temp\wer_offline_test\AbilixScratch3.0" -Yes
```

期望：安装后 sha256 = 新补丁包 sha，还原后 sha256 = `DF6DB241…`；备份/记录文件见目标目录与安装包目录。

## 4. 注意

- 安装包里的预编译内容与函数库是**绑定**的：改了 `我的函数库.srhs`（增删函数）就必须重新编译并
  替换 `browser_assets.patched` + `编译信息.txt`，否则装出来的「我的函数」还是旧函数列表。
- 安装/还原脚本内置了原版 sha 常量 `DF6DB241…`；换 IDE 版本（原版包不同）时脚本会拒绝安装，
  需要重新编译，不能只替换 binary。
- 所有测试只写临时副本 / `-Target`，不要直接对真实安装目录跑安装（真实 Program Files 需要 UAC，
  且应留给最终用户用 .cmd 提权安装）。
