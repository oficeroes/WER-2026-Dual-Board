## 7. 实测踩到的坑（工具已内置保护）

### 7.1 便携副本路径含中文 → 积木网页区全白（必须纯 ASCII 路径）

* 首轮按任务建议放在 `_分析临时\portable_test\AbilixScratch3.0_函数版`（父路径含"2026普级赛"、"_分析临时"）。
  现象：IDE 进程启动、工具栏/页签/菜单正常，但**网页内容区纯白**；CEF 无子进程、无 `debug.log`；
  控制台日志里路径中的中文变成 `?`（`AbilixScratch3.0_鍑芥暟鐗?AbilixScratch3.0_Data`）。
* 把同一份副本移到 `D:\UserData\portable_func_test\AbilixScratch3.0_FuncLib`（纯 ASCII）→
  **完全正常**：CEF 子进程 `ZFGameBrowser.exe` 出现，积木区/分类/函数/Python 全部渲染。
* 结论：软件内嵌 CEF 的资源路径走了 ANSI 转换，**非 ASCII 字符会丢**。
* 工具保护：`创建便携函数版.py` 默认目标 `%USERPROFILE%\AbilixScratch3.0_FuncLib`（ASCII），
  目标路径含非 ASCII 时**默认拒绝**（提示改 ASCII 或显式 `--allow-non-ascii`）。
  反面截图留在 `_路径含中文_白屏复现（未采用）\`。

### 7.2 软件内置「清空数据」一次性开关（已内置备份 + 置 0）

* 首次启动便携副本后，`%LocalLow%\partnerx\AbilixScratch3_0\standalonewindows\` 被**整体删除重建**
  （真实 AppData 里 110/112 项目目录、111 原有 6 个项目目录全消失，config 被重建成 1 条新项目）。
* 反编译定位（Lead 复核）：`ApplicationEntry.HandleSanBoxRes()` 启动时若
  `PlayerPrefsMgr.bClearAppDatas` 为 true → 删除 `{persistentDataPath}/standalonewindows/`；
  其 getter `PlayerPrefs.GetInt("clear_app_data_switch", 1)` **默认值为 1**，清理后自动置 0（一次性）。
* 本次是"一次性开关被消费"（之后注册表 `clear_app_data_switch_h107047456=0`）；AppData 已按备份完整恢复。
* 工具保护：创建脚本读取 `HKCU\Software\partnerx\AbilixScratch3.0\clear_app_data_switch_h*`：
  为 1/缺失时先**备份整个 AbilixProjects**（到目标同级 `_AppData备份` 目录）再把开关置 0；
  可用 `--no-fix-registry` / `--no-appdata-backup` 关闭。说明.md §6.2 有完整说明。

### 7.3 Program Files 下普通用户无法建硬链接 → 自动回退整份复制

* `os.link` 对 `D:\Program Files\...` 源文件报 `[WinError 5] 拒绝访问`（创建硬链接需要源文件的
  "修改属性"权限，普通用户对 Program Files 没有）→ 实际 1725 个文件回退 `shutil.copy2`。
* 结果仍正确（1727 文件/406.7 MB 完全一致）；只是空间收益没有了：多占约 407 MB（+补丁备份 81 MB）。
* 工具行为：报告里明确打印"硬链接 N / 独立复制 N / 回退复制 N"；用管理员运行则可硬链接省空间（说明.md §4）。

1. 按 `说明.md` §2：先在 IDE 建好函数 → 保存为 `WER_函数库\我的函数库.srhs`；
2. 双击 `创建便携函数版.cmd`（其他安装路径用 `--source`；**目标路径必须纯 ASCII**）；
3. 双击桌面「AbilixScratch3.0 函数版」→ 菜单「文件 → 新建」→ 左侧「函数」分类应出现函数调用块；
4. 验证证据可对照：新项目临时文件在其 `AppData\...\AbilixProjects\111\<时间戳>\abilixProject.srh`，
   里面应能看到 `procedures_defnoreturn` 定义（个数 = 我的函数库函数数）。

## 11. 风险 / 限制

1. **路径必须纯 ASCII**（已内置拒绝 + 文档）；若用户坚持其它路径，可用 `--allow-non-ascii`，但白屏风险自负。
2. **首次启动会消费"清空数据"开关**：工具已备份+置 0；若用户用 `--no-fix-registry` 跳过、且开关恰好为 1，
   首次启动会清空 IDE 项目列表（软件自身行为，非工具 bug）。
3. 便携版与安装版**共用 AppData 项目列表**：两版本不要同时开；便携版不隔离项目数据。
4. 安装版升级后：便携副本仍是旧版本（独立副本），需删除重建才能获得新版功能。
5. 补丁只改简中 `defaultcode`；繁中/英文模板保持官方原样（框架约定）。
6. 真机运动/标定仍需上车验证（与默认模板补丁无关）。
