WER 原生函数积木 · 离线安装包 使用说明
==========================================

本安装包的作用
--------------
给 AbilixScratch3.0（能力风暴 Scratch 3.0）装上「我的函数」原生积木：
  · 安装后，新建/打开任意项目，左侧积木分类里会多出「我的函数」分类；
  · 可以把函数积木直接拖进脚本，运行时自动生成对应的 Python 函数定义；
  · 安装只改一个文件：browser_assets（IDE 的界面资源包），不需要 Python、不需要联网。

内含文件
--------
  browser_assets.patched   预编译好的界面资源包（约 81 MB），内核内容 = 原版 + 「我的函数」积木
  安装原生积木(离线).cmd    双击这个来安装（会自动申请管理员权限）
  还原原版(离线).cmd        双击这个来还原成原版
  安装.ps1                 安装脚本（PowerShell 5.1，cmd 会自动调用，一般不用直接运行）
  还原.ps1                 还原脚本（同上）
  编译信息.txt             编译记录：函数库、补丁包、原版包的 sha256 等信息
  prelude.py               编译时提取的 Python 前奏（仅作记录，安装时用不到）


三步安装
--------
第 1 步：完全关闭 AbilixScratch3.0（安装程序检测到它有进程会拒绝安装）。

第 2 步：双击「安装原生积木(离线).cmd」，在系统弹出的 UAC 提示里点「是」。
         程序会自动定位安装目录（默认 D:\Program Files\AbilixScratch3.0），
         自动把当前 browser_assets 备份成同一目录下的
         browser_assets.备份-年月日-时分秒，然后写入补丁版并做 sha256 校验。
         看到 [DONE] 就是装好了。

第 3 步：打开 AbilixScratch3.0，新建项目，左侧分类中应出现「我的函数」，
         里面能看到 func_Hello 等函数积木。拖一个进脚本即可使用。

如果 IDE 装在别的盘 / 别的目录（或安装目录不是默认的 D:\Program Files\AbilixScratch3.0），
请用命令行指定安装根目录：
  powershell -NoProfile -ExecutionPolicy Bypass -File "安装.ps1" -Target "E:\Program Files\AbilixScratch3.0"
（-Target 也可以直接指向 browser_assets 这个文件本身；加 -Yes 可跳过交互确认。）


还原成原版
----------
双击「还原原版(离线).cmd」，点「是」；脚本会自动找目标目录里最新的
browser_assets.备份-* 备份，校验 sha256 后覆盖回去，看到 [DONE] 即还原完成。
想指定某个备份文件：
  powershell -NoProfile -ExecutionPolicy Bypass -File "还原.ps1" -Backup "D:\...\browser_assets.备份-20261111-140000" -Yes


管理员权限与 UAC
----------------
安装目录通常在 C: 或 D: 的 Program Files 下，普通用户没有写权限，所以安装/还原都需要
管理员权限。「.cmd」会自动弹 UAC 请求提权；如果你在 UAC 提示里点了「否」，什么都不会改，
重新双击、点「是」即可。也可以右键 .cmd →「以管理员身份运行」。


安全性与可回退
--------------
  · 安装前必定先在目标同目录备份一份当前 browser_assets（sha256 校验通过才继续）；
  · 安装写入后会再算一次 sha256，与 编译信息.txt 里的「补丁包sha256」不一致会自动回滚；
  · 还原时会先把当前的包另存为 browser_assets.还原前备份-*，再写回原版；
  · 每一步都会在 安装包 目录里生成「安装记录-*.txt / 还原记录-*.txt」，失败原因也记在里面。
  · 不会写注册表、不会装服务、不会联网、不动 AppData 里的工程文件。


已知限制（重要）
----------------
  · 本安装包里的「我的函数」内容（函数列表）是编译时定死的，对应当前这一份
    「我的函数库.srhs」；装好后新拖的函数积木都在这个预编译包里。
  · 如果之后改了函数库（增删函数），需要重新生成补丁包：把整个 WER_函数库 文件夹拷到
    一台有 Python 3 + Chrome 的电脑上，在 WER_函数库 目录里运行
    「工具\原生积木\安装原生积木.cmd」（或按 工具\原生积木\离线安装包\重新编译说明.md
    的命令重新 build），再把新的 browser_assets.patched 覆盖到本安装包里即可。
  · 只支持本机这一份 AbilixScratch3.0 的原版资源包（sha256 见 编译信息.txt 的
    「原版资源包sha256」）。如果目标电脑的 IDE 版本不同（资源包 sha 不是这个值），
    安装脚本会拒绝安装并给出提示——那种情况请在目标电脑上重新编译，不要强行覆盖。
  · 安装后如果 IDE 的「我的函数」分类里积木名字还是旧的，请确认装的是最新补丁包，
    并在 IDE 里按 Ctrl+F5 / 重启 IDE 强制刷新界面缓存。


常见问题
--------
Q: 提示「当前资源包已经是打过补丁的版本」？
A: 说明已经装过。想更新函数库，先跑一次「还原原版(离线).cmd」，再装新包。

Q: 提示「当前资源包不是原版，也不是本补丁包」？
A: 目标电脑的 IDE 版本/资源包和编译时不一致（或之前被别的工具改过）。先在「还原原版」里
   选一个原版备份恢复，或从同版本电脑拷一份原版 browser_assets 再装；仍不行请重新编译。

Q: 提示「检测到 AbilixScratch3.0 正在运行」？
A: 关闭 IDE（包括后台残留进程）后重试。安装程序不会强行结束 IDE。

Q: 提示需要管理员权限 / 目录不可写？
A: 用 .cmd 启动（它会自动请求 UAC），或右键「以管理员身份运行」。

Q: 安装后想换回原版但备份被删了？
A: 从一台同版本、未打过补丁的电脑上拷 AbilixScratch3.0_Data\Resources\browser_assets
   覆盖回去；也可以用「还原原版(离线).cmd -Backup <原版文件>」指定来源（脚本会校验 sha）。

Q: 杀毒软件报警？
A: 脚本只做文件复制 + sha256 计算，可查看 安装.ps1 / 还原.ps1 源码（纯文本）。


技术信息
--------
  · 安装脚本要求 Windows PowerShell 5.1（Win10/Win11 自带），不依赖 Python / 联网；
  · 安装位置：<安装根目录>\AbilixScratch3.0_Data\Resources\browser_assets
    （实际目录名以目标电脑为准，脚本会自动识别 _Data / Data 等变体）；
  · 完整校验值、函数列表、编译时间见同目录 编译信息.txt；
  · 工具与源码见 WER_函数库\工具\原生积木\（开发者用，安装时不需要）。
