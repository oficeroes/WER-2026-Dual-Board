## 11. 2026-11-11 18:20 修复记录：提权窗口里 Chrome 失效 → 安装改为两段式

**用户实测失败**（18:18，真实安装、中文路径项目目录）：备份成功后报

```
✘ 失败：真实引擎生成函数库 Python 失败（退出码 3）。
harness 未返回有效结果；Chrome returncode=0 timedOut=False
[NOT APPLIED] Installation failed.
```

**定位过程**：

1. 失败现场 `library_validate.json`：`chrome.elapsedMs=80`、`domSnippet` 空、stdout/stderr 空 → Chrome 启动即退出、不产出 DOM；静态 XML 校验是通过的。
2. 用**同一份失败时解包的 web root**（`_分析临时/native_work/build/install_20261111_181823/web`）在普通权限下重跑 `run_validate.py`：**成功**（11/11 块渲染、Python 24 行、py_compile 通过）。
3. 普通权限 `build`：**成功**（2.2s 解包、5.6s 引擎+打包，prelude 61 字符）。
4. → 唯一差异是**安装 cmd 在管理员提权窗口里跑**：提权进程里 Chrome 157 的无头模式失效（本机 Chrome 157.0.8103.40 实测）。
