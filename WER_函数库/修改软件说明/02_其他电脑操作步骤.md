# 02 · 在另一台电脑上安装（逐步照做）

> 读者：要在**别的电脑**上复现的老师 / 技术同学。
> 目标：给那台电脑上的 AbilixScratch3.0 打上原生函数积木补丁，让左侧出现「我的函数」分类。
> 本机（开发机）的验证数据见 [05_本机验证记录.md](05_本机验证记录.md)；原理见 [01_原理与改动点.md](01_原理与改动点.md)。

---

## 0. 准备清单（先确认这 5 件事）

| # | 检查项 | 要求 | 不满足时 |
| --- | --- | --- | --- |
| 1 | 操作系统 | Windows 10/11 | — |
| 2 | AbilixScratch3.0 | 已安装，版本 **1.0.3.4**（与开发机同版本） | 版本不同会警告；可能可用但需先备份，见 §8 |
| 3 | 权限 | 有一个**管理员**账户；双击 UAC 时能点「是」 | 没有管理员权限 → 用便携版（§7） |
| 4 | Python | 已安装 Python **3.8+**（建议 3.12），命令行 `python` 或 `py -3` 能找到 | 装 Python；或只用「复制补丁包」备选方案（§7.3，不推荐新手） |
| 5 | 浏览器 | 装有 **Chrome 或 Edge**（安装时用真实浏览器引擎生成函数定义） | 装 Chrome/Edge |

另外：

- **关闭 AbilixScratch3.0**（含后台进程）。
- 复制整个 `WER_函数库` 文件夹到那台电脑（**不能只复制 .cmd**：`工具\底层\`、`工具\验证\`、`我的函数库.srhs` 都是必需的；整套目录可以放任意位置，但内部结构不要改）。
- 如果那台电脑的软件装在非默认路径（不是 `D:\Program Files\AbilixScratch3.0`），请看 §6 末尾的「非默认安装路径」。
- 建议先做一份系统/软件备份（至少记住软件版本）。

---

## 1. 第 1 步：拷贝 `WER_函数库` 文件夹

把整个文件夹复制到目标电脑（U 盘 / 网盘均可），例如 `D:\WER_函数库`。
需要的目录结构（缺一不可）：

```
WER_函数库\
├─ 我的函数库.srhs                 ← 要安装的函数库
├─ 工具\
│   ├─ 原生积木\
│   │   ├─ 安装原生积木.cmd
│   │   ├─ 状态检查.cmd
│   │   ├─ 还原原版.cmd
│   │   ├─ 原生积木核心.py
│   │   └─ 备份\                  ← 会自动生成原始资源包备份
│   ├─ 底层\                      ← zfb 打包库、srh 解析库（必需）
│   └─ 验证\                      ← run_validate.py（生成函数定义时必需）
└─ 示例\WER函数库.srhs            ← 可选，但建议带上
```

> 提示：把 `WER_函数库` 放在**纯英文路径**下最稳（本工具本身支持中文路径，但少数电脑上的脚本/杀软对中文路径不友好）。

---

## 2. 第 2 步：确认软件基线（只看不改）

双击 **`工具\原生积木\状态检查.cmd`**（不需要管理员，只读）。

正常应看到类似输出（原版未打补丁的电脑）：

```
==============================================================================
原生积木状态
==============================================================================
  资源包      : D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets
  大小/hash   : 81.3 MB / df6db241752d42bff2995fcd24521e070adf9eb5d96e870148f9dc51690edc40
  管理员      : 否（安装/还原需要管理员）
  IDE 运行    : 否
  原生积木    : 未打补丁（原版资源包）
  备份        : 0 份
...
```

**核对 hash**：`df6db241…edc40` 与开发机原版一致 → 版本相同，可按本流程安装。
如果 hash 不同：说明软件版本/资源包不一样。工具会警告「这不像本机记录的原始资源包」但仍会先备份再编译；若 IDE 出现异常，用 `还原原版.cmd` 复原。**升级后的软件重装注意见 §8**。

> 如果状态检查显示「已打补丁」，说明这台电脑以前装过：直接跳到第 5 步验证，或先按 04 文档重装。

---

## 3. 第 3 步：关闭 IDE

关闭 AbilixScratch3.0 所有窗口；任务管理器里确认没有 `AbilixScratch3.0.exe`。
工具在检测到 IDE 运行时会拒绝安装（防止替换正在使用的资源文件）；确认要冒险可加 `--force`，**不建议**。

---

## 4. 第 4 步：双击安装

双击 **`工具\原生积木\安装原生积木.cmd`**：

1. 第一个黑窗口先做**编译**（普通权限，不弹 UAC、约 10～30 秒）：解包资源包、调用真实积木引擎生成函数定义。
2. 编译完成后**才弹 UAC** → 点「**是**」（只做替换，几秒完成）。
   - 请**直接双击**，不要右键「以管理员身份运行」；管理员窗口里浏览器引擎无法运行。
3. 黑窗口输出（数字随函数库变化）：

```
原生积木：编译函数库
  函数库      : ...\WER_函数库\我的函数库.srhs
  原始资源包  : ...\Resources\browser_assets
  输出补丁包  : ...
原始资源包校验：...
· 当前是未打补丁的资源包；先备份再编译。
备份：...\WER_函数库\工具\原生积木\备份\browser_assets.原始.df6db241752d.bin（81.3 MB）
· 解包原始资源包（约 80 MB / 6600 条目）…
· 调用真实 Blockly 引擎生成函数库 Python …
...
安装完成 ✔
  资源包：D:\Program Files\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets
  大小  ：81.3 MB（增加 3.9 KB）
  sha256：...
  函数  ：1 个（func_Hello）
打开 IDE → 左侧「我的函数」分类 → 拖积木。
还原方法：以管理员运行「还原原版.cmd」（备份在 ...\工具\原生积木\备份）。
```

3. 看到 `[DONE] Native blocks are installed. Open AbilixScratch3.0 and look for the "My Functions" category.` 即成功。
4. 按任意键关窗口。

> 耗时：先编译约 10～30 秒（不弹 UAC），然后才弹 UAC、替换几秒完成。看起来「卡住」是正常的，别关窗口。
> **不要**右键「以管理员身份运行」：管理员窗口里浏览器引擎无法运行，新版脚本会自动分「普通权限编译 → UAC 安装」两段。
> 安装前会自动把原版资源包备份到 `工具\原生积木\备份\browser_assets.原始.<sha前12位>.bin`（约 81 MB）。**这个备份不要删。**

---

## 5. 第 5 步：打开 IDE 验证

1. 打开 AbilixScratch3.0 → 积木编程 → 新建项目（或打开一个简单项目）。
2. 左侧分类栏底部应有紫色「**我的函数**」分类。
3. 点开分类，逐个拖 1～2 个函数块（如 `func_Init`、`func_Stop`）到 `start` 后面。
4. 右侧 Python 面板应出现：

   - 程序开头有 `def func_Hello():`（或你库里的函数）等定义；
   - `main()` 里有 `func_Init()`、`func_Stop()` 调用；
   - 文件头/import 仍正常（`#<SKCON9>…`、`import threading` 等）。

5. 再试一次**不含原生块**的新项目：右侧 Python 应与没装补丁时一样（没有函数定义、没有多出来的行）。

验证表：

| 检查 | 期望 |
| --- | --- |
| 左侧紫色「我的函数」 | 有 |
| flyout 里函数块数 | = 函数库里的函数数（本机我的函数库 = 1 个 `func_Hello`；示例库 = 20 个） |
| 拖入后 Python 面板 | 有 `def func_…` 且 `main()` 有调用 |
| 新建空项目 Python | 与官方原版一致（不含原生块） |
| 状态检查 | 「原生积木：已打补丁」「是否需要重装：否（已同步）」 |

如果任何一项不符合，先看 §9 常见问题。

---

## 6. 第 6 步：留档（建议）

1. 再跑一次 `状态检查.cmd`，截图或复制输出；
2. 按 [操作记录模板.md](操作记录模板.md) 填一张记录（电脑/使用者/软件版本/资源包 sha/函数库 sha/安装时间/备份文件名/验证结果）；
3. 保存 `安装原生积木.cmd` 窗口的最后几行输出（含 sha256 和函数列表）；
4. 如果给多台电脑装，每台都要留档（补丁后资源包 sha 会因函数库不同而不同）。

### 非默认安装路径

如果软件不在 `D:\Program Files\AbilixScratch3.0`，用命令行指定：

```bat
cd /d <WER_函数库 所在目录>
python 工具\原生积木\原生积木核心.py install --assets "E:\其他路径\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets"
```

或先设置好路径用 `.cmd %*` 转发参数：

```bat
:: 方法一（推荐）：先设置环境变量再双击/运行（脚本两段式都会用它）
set "WER_ASSETS=E:\其他路径\...\Resources\browser_assets"
安装原生积木.cmd

:: 方法二：直接用核心工具（需管理员命令行）
python 原生积木核心.py install --compile-only out.bin --assets "E:\其他路径\...\browser_assets"
python 原生积木核心.py install --prebuilt out.bin --assets "E:\其他路径\...\browser_assets"
```

（新版两段式脚本通过环境变量 `WER_ASSETS` 指定非默认路径；不再接受 `--assets` 命令行参数。）

## 7. 没有管理员权限 / 没有 Python / 没有浏览器怎么办

### 7.1 没有管理员权限 → 用便携版（推荐）

`WER_函数库\工具\原生积木\便携版\` 提供免管理员方案：把已安装的软件复制到用户目录（如 `C:\Users\你\AbilixScratch3.0_FuncLib`），再给**副本**打补丁；不改安装目录、不需要 UAC、可一键删除。

- 创建：`python 创建便携函数版.py`
- 更新（改函数库后）：`python 更新便携函数版.py`（先关便携版 IDE）
- 删除：`python 删除便携版.py --yes`

详见 [工具/原生积木/便携版/说明.md](../工具/原生积木/便携版/说明.md)。
注意：便携版同样需要 Python 3.8+ 与 Chrome/Edge（创建时要在本机编译函数定义），并要求便携目录是**纯 ASCII 路径**。

### 7.2 没有 Python / 没有 Chrome 或 Edge

- 最省事：在目标电脑装 Python 和 Chrome/Edge（都能免管理员装到用户目录）。
- 或者用 7.3 的「直接复制补丁包」备选。

### 7.3 备选：直接复制已编译好的补丁包（仅限同版本软件）

如果两台电脑的**原版资源包 sha256 完全相同**，可以把开发机上打好的补丁包整份复制过去（补丁是自包含的，函数定义已编进资源包）：

1. 开发机：`原生积木核心.py build` 生成补丁包（或用安装后从真实路径复制 `browser_assets`，先备份）；
2. 目标机：关 IDE → 以管理员身份把补丁包覆盖到 `...\Resources\browser_assets`；
3. 目标机打开 IDE 验证（同第 5 步）。

**注意**：① 目标机必须先备份原版；② 只对同版本（原版 sha 相同）有效；③ 目标机若用不同函数库，需重新编译；④ 此方式没有自动备份/状态记录，建议只在批量部署且会命令行时使用。

## 8. 软件升级 / 重装之后

软件升级会覆盖 `browser_assets`，补丁随之消失。升级后：

1. 关闭 IDE；
2. 直接重新运行 `安装原生积木.cmd`（工具会用新的原版资源包 + 当前函数库重新编译，并自动备份新版本原版）；
3. 检查 `状态检查.cmd` 是否「已同步」。

**重要**：升级后**不要**用 `还原原版.cmd` 去还原——它可能把**旧版本**的资源包恢复回来，导致 IDE 版本与资源不匹配。升级后的详细处理见 [04_回滚与升级重打.md](04_回滚与升级重打.md)。

## 9. 常见问题（按现象查）

| 现象 | 处理 |
| --- | --- |
| 双击 `.cmd` 窗口一闪而过 | 没点 UAC「是」。重新双击，**看 UAC 点「是」**；或右键「以管理员身份运行」。 |
| 报 `[NOT APPLIED] Administrator rights were not granted.` | 同上（UAC 被取消/拒绝）。 |
| 报「需要管理员权限」 | 用 `.cmd` 双击并点「是」；在普通 cmd 里跑核心 py 不会自动提权。 |
| 报「IDE 正在运行（…）」 | 完全关闭 IDE（任务管理器确认 `AbilixScratch3.0.exe` 不在）再装。 |
| 报找不到 `python` / `py -3` | 安装 Python 3.8+，安装时勾选「Add python.exe to PATH」；装完重开 cmd 窗口。 |
| 报「真实引擎生成函数库 Python 失败」 | 目标电脑缺 Chrome/Edge；或浏览器被策略限制。装浏览器后重试。 |
| 报「真实引擎生成函数库 Python 失败（退出码 3）」/「harness 未返回有效结果」，且发生在管理员窗口 | 提权进程里浏览器无头模式失效（Chrome 157 实测）。用新版 `安装原生积木.cmd`（普通权限编译 → UAC 安装，两段式）重试；或改用离线包。 |
| 报「函数库里没有函数定义」 | `我的函数库.srhs` 不对/被清空：打开它确认有函数定义块。 |
| 报「函数名不是合法的 Python 标识符」 | 函数名改成纯英文/数字/下划线，且不能数字开头；重保存后重装。 |
| 报「源资源包已打过补丁」 | 说明这台电脑已经装过：通常直接重装即可（工具会找备份重新编译）；若报找不到备份，先 `还原原版.cmd` 再装。 |
| 安装成功但 IDE 里没有「我的函数」 | ① IDE 没重启；② 装的是便携副本，开的却是原版（或反过来）；③ 软件不是同一份（检查 `--assets` 路径）。 |
| 有分类但拖块后 Python 面板没 `def` | 块要接入 `start` 主程序链；确认不是空放；检查 `状态检查.cmd` 的补丁状态。 |
| 杀软拦截/文件被锁 | 把 `WER_函数库` 加入信任；关闭 IDE 后重试。 |
| 装完 IDE 启动异常/白屏 | 关 IDE，跑 `还原原版.cmd` 恢复，再排查（先确认 §2 的版本 hash）。 |

## 10. 多台电脑 / 教室部署建议

1. 先在**一台**电脑上按本流程装通，并把 `工具\原生积木\备份\` 里的原始备份、安装输出、状态截图保存好；
2. 其它电脑重复 §2～§5（每台都装：资源在本地，不能共享）；
3. 如果教室电脑同型号且无管理员权限，优先用便携版（每人一个用户目录副本，互不影响）；
4. 所有电脑建议使用**同一份 `我的函数库.srhs`**，方便统一讲解（但每台改库后都要各自重装）；
5. 学生交的工程如果用了原生块，**打开它/生成代码的那台电脑必须装了补丁**。
