# 双板通讯补丁未收录

这个目录原本包含 `browser_assets.patched`（约 **85 MB**，已打「我的函数 + 双板通讯」
补丁）和生成好的 `install_dual.cmd/.ps1`。

它们没有进入仓库，原因：

1. 超过 GitHub 单文件 100 MB 限制；
2. 包含官方 IDE 资源，不适合公开再分发；
3. 每台电脑的 IDE 版本/路径不同，补丁应由本机生成。

本仓库保留：

- 构建脚本 `WER_函数库/工具/双板通讯/构建双板通讯扩展.py`
- 运行时 prelude `双板通讯研究/实验/实验19_双板通讯积木原型/wl_prelude.py`
- 安装/还原脚本会在构建时自动生成

安装步骤见 `docs/04_安装步骤.md`。
