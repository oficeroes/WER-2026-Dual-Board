双板通讯原生积木 · 安装与使用说明
========================================

一、这是什么
  给 AbilixScratch3.0（1.0.3.4）增加一个「双板通讯」积木分类，四个积木：
    1) 设置对方主板 IP  [192.168.1.103]      —— 只做配置，不产生动作
    2) 发送 [值] 到地址 [1]                   —— 把值写到对方主板的“地址”上
    3) 接收地址 [1] 的信息                    —— 数字/变量型积木，读对方地址上的最新值（没收到时是上次保存的值或 0）
    4) 把地址 [1] 的信息保存到读写数据        —— 立刻把当前值写入主板「读写数据」（EEPROM，掉电不丢）
  两块板各跑一个程序：A 设置 IP=B、B 设置 IP=A，然后用“发送/接收”配对即可。

二、数据会保存吗？
  会。双板通讯的“地址 1~128”就是主板「读写数据」的 01~128：
  - 「接收」积木读到新数值时，会自动写入「读写数据」（同一地址最快 1 秒写一次、只在数值变化时写，
    用来保护 EEPROM 擦写寿命）；
  - 程序重新运行后、还没收到新数据时，「接收」积木会回读「读写数据」里的旧值（不会直接变 0；
    从没写过的地址读出来是 0）。
  - 想“立刻保存”（不等自动节流）就用第 4 个积木。
  - 数值范围：整数 -99999 ~ 99999。
  注意：地址 1~128 与界面「读写数据」共用，如果某些槽里已有旧数据（例如 01=3600、02=400），
  做通讯测试时建议改用 11、12 这类空地址，避免覆盖。

三、安装（约 2 分钟）
  1. 完全关闭 AbilixScratch3.0（任务管理器里不能有 AbilixScratch 进程）。
  2. 右键“以管理员身份运行”本目录下的  install_dual.cmd  （会弹 UAC，点是）。
     脚本会自动：检查 IDE 已关闭 → 备份当前资源包 → 替换 → 校验 sha256，失败自动回滚。
  3. 打开 IDE，左侧函数栏的最上方（“我的函数”旁）会出现「双板通讯」分类。
  版本校验值（安装日志里能看到）：
     原版资源包 sha256   = df6db241752d42bff2995fcd24521e070adf9eb5d96e870148f9dc51690edc40
     本补丁包 sha256     = a2515601e51174f4649722883849a94e4a47629eaef5a8af34802f22d5cb3b3b
     安装前 4 积木版的上一版 sha256 = b294b5cce4d8f8dde38bd6f6d317e57de9e934b62f9a080d6f7e152ea63b0b3a
     （更早的 3 积木版 sha256 = c3a10e50…，也支持从它直接升级）

四、最小示例（两块板）
  A 板（按钮板，IP 192.168.1.102）程序：
     设置对方主板 IP [192.168.1.103]
     永远重复 {
        发送 [计数器] 到地址 [11]
        在屏幕显示 接收地址 [12] 的信息
     }
  B 板（LED 板，IP 192.168.1.103）程序：
     设置对方主板 IP [192.168.1.102]
     永远重复 {
        发送 [计数器] 到地址 [12]
        在屏幕显示 接收地址 [11] 的信息
     }
  运行后两块屏幕应互相显示对方递增的数值。
  掉电保持：B 板收到 A 的数值后，关掉 B 的程序再重新运行，B 的“接收地址 11”会先显示上次的值。

五、对方没运行程序时能收吗？
  只要对方运行的程序里含任意「双板通讯」积木（哪怕只有“接收”），它的运行时就会自动收；
  如果对方一个程序都没在跑，就收不到（机器人没有代码在运行）。要让没开程序也能收，
  需要改 Android 常驻服务（高风险，需另行确认后才做）。

六、原理（一句话）
  积木本身不联网；生成程序时会在 robot = Robot() 之后自动注入一段“运行时”：
  用机器人自带的 gcc4.8.2 在 App 私有目录现场编译一个 C 网络助手（UDP 8990），
  由它负责两板收发；Python 侧维护“地址→最新值”的字典，并把值写进「读写数据」。

七、还原
  右键以管理员身份运行  restore_dual.cmd  （会优先用最近一次安装前的备份回滚）。
  备份在：WER_函数库\工具\原生积木\备份\browser_assets.双板通讯前-<时间戳>.bin

八、排错
  - 程序运行但收不到值：检查两块板“设置对方主板 IP”是否互指、是否在同一 WiFi；
    机器人屏幕上的 err=[] 表示运行时正常（err 非空会显示错误信息）。
  - 安装脚本报“当前资源包既不是原版也不是已知的旧补丁版”：说明这机器上装过别的补丁，
    先用 restore_dual.cmd 或原版备份还原再装。
  - 装完 IDE 打不开/分类没出现：运行 restore_dual.cmd 回滚，然后把窗口报错发我。
