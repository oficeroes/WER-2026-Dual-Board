## 1. 变量（共 27 个，软件"变量"分类里都能看到）

> 生成 Python 时，变量名会作为全局变量；`var_` 前缀是软件规范。
> **修改默认值：打开 `func_Init` 函数定义块，改里面的数字。** 直接改"变量"里的值是没用的——`func_Init` 每次运行会覆盖。

| 变量 | 初值 | 含义 | 谁在用 |
|---|---|---|---|
| `var_1cm` | 90.4 | 1 厘米对应编码器计数 | `func_ForwardCM`、`func_BackwardCM` |
| `var_1angle` | 17.8 | 1 度对应编码器计数 | `func_TurnLeft`、`func_TurnRight` |
| `var_speed` | 40 | 直行默认速度 % | Forward/Backward |
| `var_straight_Kp` | 0.005 | 直行两轮纠偏系数 | Forward/Backward |
| `var_turn_speed` | 25 | 原地转向默认速度 % | TurnLeft/TurnRight |
| `var_arm_speed` | 30 | 抬升/夹爪速度 % | ArmUp/Down、Grab/Release |
| `var_arm_time` | 0.5 | 抬升/夹爪持续时间 秒 | 同上 |
| `var_ray_white` | 1300 | 灰度白值阈值（≥ 算白/路口） | LineStep（无直接用）、LineUntilCross |
| `var_ray_speed` | 30 | 巡线速度 % | LineStep |
| `var_ray_Kp` | 0.01 | 巡线比例系数 | LineStep |
| `var_ray_Kd` | 0.001 | 巡线微分系数 | LineStep |

| `var_ready` | 1 | 已初始化标记（动作函数检查它决定要不要自动初始化） | 所有动作函数 |

| `var_err_last_9` / `var_err_last_10` | 上一次误差（微分项用） |

## 2. 逐个函数说明

> 下方"生成 Python"是软件把积木翻译出来的真实形态（省略软件自动加的 `global ...` 行和末尾 `pass`）。

### 2.1 `func_Init` — 初始化（每个程序第一步）

- 参数：无
- 生成 Python 调用：`func_Init()`
- 做的事：
  1. 写入全部校准参数（见 §1.1 初值）；
  2. `var_ee_white_9 = robot.get_ee(9)`、`var_ee_white_10 = robot.get_ee(10)`，若 <100 则回退 1300；
  3. 清空巡线历史误差；
  4. 左右驱动电机停、等待 0.05 秒；
  5. 左右驱动编码器清零；
  6. `var_ready = 1`。
- 备注：改参数就改这个函数定义里的数字；它不会被"变量"面板里的值覆盖（运行时会重新赋值）。

### 2.2 `func_Stop` — 停止

- 生成：`func_Stop()` → `robot.set_motor(1,0)`、`robot.set_motor(2,0)`、`time.sleep(0.05)`
- 用途：任何需要立刻停车的地方。

### 2.3 `func_ResetEncoder` — 编码器清零

- 生成：`func_ResetEncoder()` → `robot.reset_encoder(1)`、`robot.reset_encoder(2)`

### 2.4 `func_ForwardCM(cm)` — 前进 cm 厘米

- 参数：`cm`（>0，单位厘米）
- 生成 Python 调用：`func_ForwardCM(10)`
- 算法：
  ```
  if 未初始化: func_Init()
  func_ResetEncoder()
  while |编码器1| < cm × var_1cm:
      差值 = 编码器1 − 编码器2
      电机1 = var_speed − var_straight_Kp × 差值
      电机2 = var_speed + var_straight_Kp × 差值
      等待 0.01 秒
  电机1 = 0; 电机2 = 0; 等待 0.05 秒
  ```
- 说明：编码器定距，两轮差值做简单纠偏；`cm` 用负数会反向（不推荐，请用 `func_BackwardCM`）。

### 2.5 `func_BackwardCM(cm)` — 后退 cm 厘米

- 与 `func_ForwardCM` 对称，电机速度取负；`cm` 填正数。

### 2.6 `func_TurnLeft(deg)` / 2.7 `func_TurnRight(deg)` — 原地转向

- 参数：`deg`（>0，单位度）
- 算法：`func_ResetEncoder()`，然后
  - 左转：电机1 = `−var_turn_speed`，电机2 = `+var_turn_speed`；
  - 右转：电机1 = `+var_turn_speed`，电机2 = `−var_turn_speed`；
  - `while |编码器1| < deg × var_1angle`；结束后停车。
- 说明：原地转，目标角度 = `deg × var_1angle` 计数；`var_1angle` 不准就量一次 90° 实际转角来反推。

### 2.8 `func_DriveTime(speedL, speedR, sec)` — 双电机按时间

- 生成：`robot.set_double_motor_time(1, clamp(speedL), 2, clamp(speedR), clamp(sec, 0, 3600))`
- 用途：调试端口/方向、抢时间段的粗动作。
- 备注：该积木本身是**阻塞**的（走完才继续）。

### 2.9 `func_DriveSpeed(speedL, speedR)` — 双电机持续

- 生成：`robot.set_motor(1, clamp(speedL))`、`robot.set_motor(2, clamp(speedR))`
- 非阻塞；要自己配 `等待`/`重复执行`/`func_Stop`。

### 2.10 `func_ArmUp` / 2.11 `func_ArmDown` — 抬升

- 端口 **3**，速度 `var_arm_speed`，时间 `var_arm_time`：
  - Up：`robot.set_motor_time(3, +var_arm_speed, var_arm_time)`
  - Down：`robot.set_motor_time(3, −var_arm_speed, var_arm_time)`
- 换端口/方向：打开函数定义改下拉框与速度正负。

### 2.12 `func_Grab` / 2.13 `func_Release` — 夹爪/滚筒

- 端口 **4**，逻辑同上（Grab 正转、Release 反转）。

### 2.14 `func_LineStep` — 巡线 PID 单步（内部函数）

- 生成 Python 体：
  ```python
  var_err_9  = (var_ee_white_9  - robot.get_gray(9))
  var_err_10 = (var_ee_white_10 - robot.get_gray(10))
  var_pid_9  = ((var_ray_Kp * var_err_9)  + (var_ray_Kd * (var_err_9  - var_err_last_9)))
  var_pid_10 = ((var_ray_Kp * var_err_10) + (var_ray_Kd * (var_err_10 - var_err_last_10)))
  var_err_last_9 = var_err_9
  var_err_last_10 = var_err_10
  robot.set_motor(1, clamp(var_ray_speed + var_pid_9))
  robot.set_motor(2, clamp(var_ray_speed + var_pid_10))
  time.sleep(0.01)
  ```
- 一般不用直接拖它；`func_LineTime` / `func_LineUntilCross` 已经包好。也可以自己写循环时反复调用它。

### 2.15 `func_LineTime(sec)` — 巡线 sec 秒

- 生成骨架：
  ```python
  func_Init()  # 若未初始化
  var_err_last_9 = 0; var_err_last_10 = 0
  robot.reset_timer(2)
  while not robot.get_timer_ms(2) >= (sec * 1000):
      func_LineStep()
  停车; 等待 0.05; 清误差
  ```
- 备注：用 **定时器 2**；如果你自己的程序也要用定时器，注意避开。

### 2.16 `func_LineUntilCross` — 巡线到路口

- 生成骨架：
  ```python
  func_Init()  # 若未初始化
  清误差
  while not robot.get_gray(7) >= var_ray_white:
      if robot.get_gray(8) >= var_ray_white:
          break
      func_LineStep()
  停车; 等待 0.05; 清误差
  ```
- 语义：巡线（灰度 9/10）直到 **7 或 8** 任一读到白值（≥ `var_ray_white`）→ 停车。
- 注意：和 `主程序.py` 一样，路口判定把"白"当特征（`var_ray_white` 是白值阈值）；如果场地/灰度极性不同，改 `var_ray_white` 或改比较方向。

### 2.17 `func_WaitStartKey` — 等 Start 键

- 生成：`while not robot.check_key(1) == 1: time.sleep(0.02)`，之后 `time.sleep(0.2)` 防抖。
- 按键端口 1 = 确认键。
- **注意**：`get_key` 积木不在 SKCON9 静态工具箱里（但积木定义/生成器存在，本项目 XML 里可直接用）；
  如果你的控制器没有 Start 键，请改用下面的 `func_WaitTouch`（主程序.py 就是用触碰1启动）。

### 2.18 `func_WaitTouch` — 等触碰传感器（推荐用于启动/分段）

- 生成：`while not robot.get_touch(1) == 1: time.sleep(0.02)`，之后 `time.sleep(0.2)` 防抖。
- 与 `主程序.py` 的启动方式一致（触碰传感器接端口 1）；比 Start 键更通用。

### 2.19 `func_Show(text)` — 屏幕显示文字

- 生成：`robot.print(text, '\n')`
- 参数槽里放 **文本** 块（如 `hello`）或文本变量；数字也可以（会转成字符串拼接）。

### 2.20 `func_Beep` — 提示音

- 生成：`robot.play('dazhaohu_c0.mp3')`（内置打招呼声）。
- 想换声音：打开函数定义，把 `play_sound` 积木的下拉框换成别的内置声音（或改成录音文件）。

## 3. 生成/修改函数库

- 唯一事实来源：`工具/build_library.py`（函数体定义）+ `工具/block_xml.py`（积木 XML DSL）。
- 改完运行：
  ```bat
  python 工具\build_library.py
  ```
  会覆盖生成 `WER函数库.srh` 和 `WER函数库.srhs`（不要手改这两个文件，会被覆盖）。
- 新增函数：在 `build_library.py` 的 `build_tops()` 里加一个 `build_xxx()`，并在 `build_start()` 里按需加示例调用。
- 校验：`python 工具\验证\run_validate.py WER函数库.srh`（详见 `工具/验证/验证方法.md`）。
- 积木 XML 的字段/输入名规格：见 `工具/规格/block_schemas.json` 与 `工具/规格/积木XML规格.md`。
