# 新建项目默认模板补丁（可选）—— 使用说明

> 目标：让 AbilixScratch3.0 **新建项目时，工作区里直接自带 WER 函数库**
> （20 个函数定义 + 27 个变量声明 + 1 个 start 示例块），打开积木编程即可在「函数」分类里拖动调用，
> 不用先打开 `WER函数库.srhs`。
>
> ⚠ 这是**可选的高级功能**，需要**管理员权限**修改软件安装目录。不装补丁也不影响其他交付物：
> 平时用「文件 → 打开 `WER函数库.srhs`」或「安装到 IDE 项目列表」同样可以使用函数库。

---

## 1. 目录内容

| 文件 | 作用 |
|---|---|
| `patch_browser_assets.py` | 补丁主脚本（解包/改 1 个条目/重打包/逐文件 sha256 自检/安装） |
| `一键应用补丁(管理员).cmd` | **推荐入口**：右键/双击 → 自动请求管理员 → 打补丁 |
| `还原默认模板.py` | 从备份恢复（撤销补丁） |
| `还原默认模板(管理员).cmd` | **推荐还原入口**：列出备份→恢复 |
| `函数库defaultcode片段.xml` | 从 `WER函数库.srh` 自动抽取的 defaultcode 片段（`<xml>` + `<variables>` + 全部顶层 block + start） |
| `自检报告.md` | 本机在 85MB 副本上的 roundtrip / 逐文件 sha256 / 真实 Blockly 加载自检结果 |

依赖：Windows 自带 Python 或本机 DSH 运行时 Python（.cmd 内已写优先路径，找不到会退回 `python`）。

---

## 2. 怎么打补丁（推荐步骤）

1. **关闭 AbilixScratch3.0**（重要：IDE 运行时改资源包可能被占用/退出时覆盖）。
2. 双击 `一键应用补丁(管理员).cmd`，在 UAC 弹窗点「是」。
3. 等待脚本跑完（85MB 解包→改→重打包→自检，约 10~40 秒），看到 `DONE` 即可。
4. 重新打开 AbilixScratch3.0 → 新建项目 → 工作区应自带函数库积木；
   「函数」分类里能看到 `func_Init` / `func_ForwardCM(cm)` 等 20 个可拖动调用块。
5. 如要撤销：双击 `还原默认模板(管理员).cmd`。

> 命令行等价做法（管理员命令行）：
> ```
> python patch_browser_assets.py --install
> python 还原默认模板.py --apply
> ```

## 3. 补丁到底改了什么（可审计）

补丁对象：`D:\Program Files\AbilixScratch3.0\AbilixScratch3_0_Data\Resources\browser_assets`
（自定义 `zfbRes_v1` 二进制资源包，6645 个条目）

* **只改 1 个条目**：`Blockly_Code/maingui_init.js`
  —— 文件第 5 行 `var defaultcode = '...'` 的字符串内容（简中默认模板）；
* 其余 **6644 个条目逐字节不变**（脚本自动逐条目 sha256 校验，失败会中止且不安装）；
* 繁中 `defaultcodeTr`、英文 `defaultcodeEn` **默认不动**（`--langs all` 才三语全改）；
* 打补丁前自动备份原文件为：`browser_assets.备份-<yyyyMMdd-HHmmss>`（同目录）。

原理（C# 反编译 + 真实资源包实证）：
新建项目 → `maingui.createProject()` → `workspace.clear()` → `maingui.importDefaultCode()`
→ `Blockly.Xml.textToDom(defaultcode + 当前空工作区XML)`（浏览器解析器只取第一个 `<xml>` 根）
→ `Blockly.Xml.domToWorkspace(...)`。所以把「函数库片段」写进 `defaultcode`，新项目就自带。

## 4. 风险与注意事项（必读）

1. **需要管理员权限**：本机普通用户对 `D:\Program Files\...` 只读；脚本会用 UAC 提权，若无权限会明确报错并**不改动任何文件**。
2. **升级/重装软件会覆盖补丁**：AbilixScratch3.0 升级/重装后 `browser_assets` 被替换，需要**重新双击 `一键应用补丁(管理员).cmd`**。
3. **杀毒软件可能拦截**：脚本会重写 81MB 的应用程序资源文件，个别杀软可能提示；请先看提示内容确认是本补丁。
4. **还原方法**：双击 `还原默认模板(管理员).cmd`，或
   `python 还原默认模板.py --apply`（会自动选最新备份，并先把当前文件备份成 `browser_assets.还原前-<时间>`）。
5. **新建项目后变量/函数已声明**：片段包含 `<variables>`（27 个变量声明），不会出现“变量未声明”问题。
6. 补丁**不影响打开已有项目**（.srhs 自带完整工作区，加载时覆盖默认模板）。
7. 若打补丁后 IDE 异常（理论上不应发生）：关闭 IDE → 还原脚本恢复 → 重新打开 IDE 即可；原始备份仍在同目录。
8. 本补丁只针对**本机这份安装**；换电脑/新装软件需重新运行。
9. **启动目录/权限**：若把本工具放到中文路径或网络盘，建议先复制到本地再运行（.cmd 已 `cd /d "%~dp0"`）。

## 5. 自检与验证

见同目录 `自检报告.md`。摘要（2026-11-10 本机实测）：

* 纯 roundtrip（解包→原样重打包）与原始 `browser_assets` **逐字节一致**；
* 打补丁后包内 6645 条目中**只有 `Blockly_Code/maingui_init.js` 变化**（5242→54599 字节），其它 6644 条 sha256 全部一致；
* 从补丁包读回 `defaultcode` 并反转义，与期望片段**完全相等**（48594 字符：21 顶层块=20 函数+start，27 变量）；
* 用 Chrome headless + 真实 Blockly 引擎**按 `importDefaultCode` 完全相同的方式**（defaultcode + 空工作区 XML 双根拼接）加载：成功，得到 20 个函数定义、1 个 start、27 个变量、413 个块，无 JS 错误；
* 用模拟安装目录测过还原：备份恢复后 sha256 与原始文件**完全一致**。

**尚未做的验证（建议用户首次使用时确认）**：
* 真实安装到 `D:\Program Files` 后，启动真实 IDE → 新建项目 → 肉眼确认函数分类出现库函数（本机普通用户无写权限，未做真实写入；Lead 最终整合时执行）。

## 6. 常见问题

**Q: 双击 .cmd 一闪而过？**
A: 先看是否被 UAC 拒绝；或用管理员 PowerShell 运行 `一键应用补丁(管理员).cmd`；也可直接看命令行输出。

**Q: 提示“没有写入权限”？**
A: 说明没以管理员运行。请对 .cmd 右键 →「以管理员身份运行」，或从管理员命令行执行 python 命令。

**Q: 提示“纯 roundtrip 后字节不一致”？**
A: 说明本机 `browser_assets` 与脚本预期格式不同（可能被其他工具改过/版本不同）。此时脚本**不会安装**，原文件不受影响。可加 `--skip-identical-check` 强制继续（不建议），或先用 `python patch_browser_assets.py --verify-only 旧 新` 分析。

**Q: 只想先看会改什么、不写安装目录？**
A:
```
python patch_browser_assets.py --assets 副本\browser_assets --out 副本\browser_assets.patched
python patch_browser_assets.py --verify-only 副本\browser_assets 副本\browser_assets.patched
```

**Q: 升级后忘了重打补丁？**
A: 函数分类少了库函数就是没打上；重新运行 `一键应用补丁(管理员).cmd` 即可（会重新备份当时版本）。

---

## 7. 恢复出厂设置（极端情况）

如果安装目录里的 `browser_assets` 和所有备份都损坏：从软件安装包/另一台电脑复制原始的
`AbilixScratch3.0_Data\Resources\browser_assets` 覆盖回来即可；`还原默认模板.py --backup <该文件> --apply` 也支持从任意原始包恢复。
