# 旧方案归档：模板注入（已废弃）

这里存放的是**第一、二轮**「新建项目默认模板注入」方案的工具，已被**原生函数积木**方案取代。

## 为什么废弃

用户实际需要的是「**内部渲染**」：函数块要像 IDE 自带的电机块一样，在工具箱内部本身存在、任何项目里都能直接拖用；
而不是靠修改「新建项目默认模板」让每个新项目里先出现函数定义。
前者已由 `WER_函数库/工具/原生积木/` 实现（新增 `abilix_userlib.js` + 在 3 个工具箱里加「我的函数」分类 + 生成 Python 时条件注入函数定义）。

## 归档内容

| 目录 | 原方案作用 | 状态 |
|---|---|---|
| `框架/` | Python 版：把我的函数库同步进 `maingui_init.js` 的 defaultcode（新建项目自带函数），含同步/还原/查看/校验/生成新项目 | 已废弃，不要使用 |
| `仅PowerShell/` | 同上，用纯 PowerShell 5.1 实现（无 Python 电脑用），曾与 Python 版产出逐字节相同的补丁包 | 已废弃，不要使用 |
| `便携版_旧方案/` | 上一轮（模板注入版）便携工具：复制安装目录 + 打默认模板补丁 + 桌面快捷方式 | 已废弃，不要使用；现行便携版见下方入口 |
