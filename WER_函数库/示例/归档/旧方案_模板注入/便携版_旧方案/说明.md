# AbilixScratch3.0「函数版」便携副本 —— 使用说明

> 目标：**不用管理员权限、不修改安装目录**，得到一份"每次新建项目都自带我自己的函数库"的
> AbilixScratch3.0。双击创建脚本 → 得到一个便携副本 + 桌面快捷方式，之后正常使用 IDE 即可。
>
> 适用：本机普通用户对 `D:\Program Files\AbilixScratch3.0` 只读（安装目录打不了补丁）；
> 或者想隔离测试、不想动原软件。**原理和"修改记录"见 `WER_函数库\修改软件说明\`。**
>
> 实测环境：Windows 10/11 + AbilixScratch3.0（SKCON9，资源包 6645 条目 / 81.3MB / sha256 `df6db241…`）
> 真实 IDE 端到端验证通过（见 `WER_函数库\证据\框架端到端验证\`）。

## 1. 交付文件

| 文件 | 作用 |
|---|---|
| `创建便携函数版.py` / `创建便携函数版.cmd` | ★一键创建：复制软件 → 打"新建项目自带函数库"补丁 → 建桌面快捷方式 |
| `更新便携版函数库.py` / `.cmd` | 改了「我的函数库」后，把最新函数同步进已有副本（自动备份旧资源包） |
| `删除便携版.py` / `.cmd` | 删除便携副本与快捷方式（**默认演练**，加 `--yes` 才真删） |
| `便携版公共.py` | 上面三个脚本共用的底层函数（定位安装目录/复制/打补丁/注册表检查等） |
| `说明.md` | 本文件 |

依赖：**Python 3.8+（只用标准库，无需 pip install）**；以及 `WER_函数库\工具\底层\patch_browser_assets.py`。
`.cmd` 会自动找 Python（环境变量 `PYTHON_EXE` → `py -3` → `python` → 本机捆绑运行时）。
整个 `WER_函数库\` 目录可以整体拷到别的电脑用（路径全部相对/自动探测）。

## 2. 快速开始（3 步）

1. **先在 IDE 里建好自己的函数**（可选，但这是"函数版"的意义）：
   打开 IDE → 左侧「函数」→ 新建函数 / 拖积木搭函数体 → 全选函数定义块（连同 `start` 主函数）
   放进一个项目 → 另存为/保存成 **`WER_函数库\我的函数库.srhs`**（或 `.srh`）。
   > 还没有自己的函数时，工具会回退用 `WER_函数库\示例\WER函数库.srhs`（20 个示例函数），方便先看效果。
2. **双击 `创建便携函数版.cmd`**（或命令行 `python 创建便携函数版.py`）。
   等 1~3 分钟，看到 `创建完成 ✓`：得到
   - 便携副本：`%USERPROFILE%\AbilixScratch3.0_FuncLib`（默认，**纯 ASCII 路径**）
   - 桌面快捷方式：`AbilixScratch3.0 函数版.lnk`
3. **双击桌面快捷方式**启动函数版 → 菜单「文件 → 新建」（或 Ctrl+N）→ 新项目工作区就自带你的
   函数定义/变量，左侧「函数」分类里直接拖用。

> ⚠ **路径必须纯 ASCII**（不能有中文）：实测副本放在含中文的路径时，IDE 能启动但**积木网页区全白**
> （内嵌 CEF 浏览器加载不了中文路径的资源）。工具默认目标 `AbilixScratch3.0_FuncLib` 是 ASCII；
> 若你用 `--target` 指定了含中文的路径，脚本会**拒绝**（除非 `--allow-non-ascii`，不推荐）。

## 3. 三个脚本怎么用

### 3.1 创建便携函数版.py

```bat
:: 最常用：自动找安装目录 D:\Program Files\AbilixScratch3.0，用 我的函数库.srhs
python 创建便携函数版.py

:: 其他电脑/自定义路径
python 创建便携函数版.py --source "E:\Program Files\AbilixScratch3.0" ^
    --target "D:\AbilixScratch3.0_FuncLib" --library "WER_函数库\我的函数库.srhs"

:: 只复制、不打补丁（调试用）
python 创建便携函数版.py --no-patch --no-shortcut
```

主要参数：

| 参数 | 说明 |
|---|---|
| `--source DIR` | 安装目录（默认 `D:\Program Files\AbilixScratch3.0`） |
| `--target DIR` | 便携副本输出目录（默认 `%USERPROFILE%\AbilixScratch3.0_FuncLib`，必须 ASCII） |
| `--library FILE` | 函数库源 `.srh/.srhs`（默认 `WER_函数库\我的函数库.srh/.srhs`） |
| `--shortcut-name NAME` / `--desktop DIR` | 快捷方式文件名 / 桌面目录 |
| `--no-shortcut` | 不建快捷方式 |
| `--force` | 目标已存在时删除重建 |
| `--report JSON` | 把完整报告写成 JSON（留证据） |
| `--allow-non-ascii` / `--no-fix-registry` / `--no-appdata-backup` | 危险选项，见下文说明 |

### 3.2 更新便携版函数库.py

改完「我的函数库」后运行（建议先关掉函数版）：

```bat
python 更新便携版函数库.py
python 更新便携版函数库.py --prune      :: 顺便只保留最新 2 个旧资源包备份（每个约 81MB）
python 更新便携版函数库.py --dry-run    :: 只检查、读当前模板，不写文件
```

更新流程 = 重新给副本打补丁（旧 `browser_assets` 自动备份为 `browser_assets.备份-<时间戳>`）
+ 读回 defaultcode 二次校验（与函数库生成的片段逐字符相等）+ 可选清理旧备份。

### 3.3 删除便携版.py

```bat
python 删除便携版.py           :: 演练：只显示要删什么/占多少空间
python 删除便携版.py --yes     :: 真正删除（副本目录 + 桌面快捷方式）
```

> 只删便携副本；**安装目录、IDE 项目列表（AppData）、桌面其它文件都不会动**。

## 4. 占用空间

| 场景 | 额外占用 | 说明 |
|---|---|---|
| 理想（可建硬链接） | ≈ **81MB + 补丁备份 81MB ≈ 162MB** | 407MB 的软件主体用硬链接共享安装目录数据 |
| 实测（本机普通用户） | ≈ **407MB（整份复制）+ 81MB 补丁备份 ≈ 490MB** | ⚠ 安装目录在 Program Files，普通用户对源文件没有"修改属性"权限，`os.link` 全部 `WinError 5` → 自动回退 `shutil.copy2` 整份复制；本工具会在报告里明确写出"硬链接 N 个/回退复制 N 个" |
| 每次更新 | 多一个 81MB 备份 | 可用 `--prune` 只保留最新 2 个 |

> 想省空间：用管理员身份运行一次创建脚本（管理员对 Program Files 文件有权限，硬链接就能建成功）；
> 或者创建后手工删掉便携副本里用不到的 `Uninstall\` 等（不推荐，可能影响卸载器）。

## 5. 原理（做了什么、改了哪里）

1. **复制**：把整个安装目录（1727 文件 / 406.7MB）复制到目标目录。
   - 普通文件优先 `os.link` 硬链接（同一 NTFS 卷、秒级完成、共享数据），失败自动回退 `copy2`；
   - **`browser_assets` 永远独立复制**（不能硬链接！否则打补丁会通过硬链接改坏安装目录，工具带校验强制）；
   - 复制后校验：文件数/总大小与源一致、exe 存在、browser_assets 与源的 inode 不同。
2. **打补丁**：调用 `工具\底层\patch_browser_assets.py`，对副本的
   `<副本>\AbilixScratch3.0_Data\Resources\browser_assets`（`zfbRes_v1` 自定义资源包）：
   - 解包 6645 个条目 → 只把 `Blockly_Code/maingui_init.js` 里的 `var defaultcode`（简中模板）
     替换成"函数库片段"（`<xml>` 根 + `<variables>` + 全部顶层 block，必须含 `start`）；
   - 重新打包 → 逐条目 sha256 比对，**除 maingui_init.js 外 6644 条必须逐字节不变**；
   - 原 `browser_assets` 自动备份为 `browser_assets.备份-<时间戳>`；
   - 读回新包里的 defaultcode 与函数库重新生成的片段**逐字符比对**（独立二次校验）。
3. **新建项目为什么自带函数**：软件新建项目时 C# → JS `maingui.createProject()` →
   `maingui.importDefaultCode()` 会把 `maingui_init.getDefaultCode()` 的内容加载进工作区。
   我们改的就是这个默认模板 → 新项目直接带上你的函数定义/变量，「函数」分类由
   `Blockly.Procedures.flyoutCategory()` 动态生成调用块，可直接拖。

## 6. 实测踩到的坑（非常重要，已内置保护）

### 6.1 路径含中文 → 积木网页区全白（已内置拒绝）

* 现象：便携副本放在 `...\2026普级赛\_分析临时\...\AbilixScratch3.0_函数版`（含中文）时，
  IDE 窗口/工具栏/页签正常，但**网页内容区纯白**，CEF 不创建子进程、不写 `debug.log`；
  换到纯 ASCII 路径 `D:\UserData\portable_func_test\AbilixScratch3.0_FuncLib` 后，同一份副本
  完整正常（左侧分类、工作区函数、右侧 Python 全部出现）。
* 原因：软件内嵌 CEF（`zf_cef.dll`）的路径传递做了 ANSI 转换，非 ASCII 字符会丢成 `?`。
* 保护：创建脚本默认拒绝非 ASCII 目标路径；桌面快捷方式名可以含中文（与程序路径无关）。

### 6.2 软件内置「清空数据」一次性开关（已内置备份 + 置 0）

* 实测：首次启动便携副本时，`%USERPROFILE%\AppData\LocalLow\partnerx\AbilixScratch3_0\standalonewindows\`
  被整个删除重建（项目列表/全部临时项目消失）。反编译定位：`ApplicationEntry.HandleSanBoxRes()`
  在 `PlayerPrefsMgr.bClearAppDatas == true` 时清理，而该开关 getter 默认值就是 **1**，
  清理后自动置 0（一次性）。
* 保护：创建脚本会读注册表 `HKCU\Software\partnerx\AbilixScratch3.0\clear_app_data_switch_h*`：
  - 为 1/缺失 → **先把整个 `AbilixProjects` 备份到副本同级的
    `AbilixProjects.备份-<时间戳>-便携版创建\`**，再把开关置 0；
  - 已有备份如需找回：关掉 IDE 后把备份目录复制回
    `%USERPROFILE%\AppData\LocalLow\partnerx\AbilixScratch3_0\standalonewindows\AbilixProjects`。
  - 关闭保护：`--no-fix-registry`（自行承担清空风险）、`--no-appdata-backup`。

### 6.3 Program Files 里建不了硬链接

本机普通用户对 `D:\Program Files\AbilixScratch3.0\*` 只有读权限，创建硬链接需要源文件的
"修改属性"权限，故 `os.link` 报 `[WinError 5] 拒绝访问`，工具自动回退整份复制（约 407MB）。
这不是错误，报告里会写"硬链接 0 / 回退复制 1725"。

### 6.4 与安装版共用 AppData

便携版和安装版使用**同一份** IDE 项目列表
（`...\standalonewindows\AbilixProjects\111\`，临时项目按机器人数 110/111/112 分目录）：
* 两个版本**不要同时启动**（退出时都会回写项目列表配置）；
* 便携版里的项目只是"临时项目"，和安装版共用；想彻底隔离可另建 Windows 用户账户；
* 删除便携版**不会**删除这些项目（在 AppData 里，本工具不碰）。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 双击 .cmd 闪退 | 用命令行运行 `python 创建便携函数版.py` 看报错；或设置环境变量 `PYTHON_EXE` 指向 python.exe |
| 启动后积木区白屏 | 99% 是路径含中文/非 ASCII：把副本挪到 `D:\AbilixScratch3.0_FuncLib` 这类纯 ASCII 路径（删掉重建最快） |
| 新建项目里没有函数 | ① 确认 `我的函数库.srhs` 里确实有 `procedures_defnoreturn` 函数；② 改完后跑过 `更新便携版函数库.py`；③ 新项目要在更新**之后**新建 |
| 更新时提示"IDE 正在运行" | 先关闭函数版（任务管理器确认无 `AbilixScratch3.0.exe`），再更新 |
| 想把补丁撤掉 | 副本里 `AbilixScratch3.0_Data\Resources\browser_assets.备份-<时间戳>` 改名回 `browser_assets` 即可 |
| 安装版升级/重装后 | 安装版升级不影响便携副本；但想同步安装版的新功能 → 删掉旧副本重新 `创建便携函数版.py` |
| 打补丁自检失败 | 不会写坏文件（补丁器先自检后安装）；把完整输出/`--report` JSON 发出来排查 |

## 8. 迁移到其他电脑

1. 把整个 `WER_函数库\` 目录复制过去（保持 `工具\底层\`、`工具\便携版\`、`示例\` 相对结构）；
2. 装 Python 3.8+（勾选 Add to PATH）；
3. 在新电脑上双击 `创建便携函数版.cmd`（默认安装路径相同的话无需参数；
   不同盘/不同版本用 `--source` 指定安装目录）；
4. 脚本会打印它实际用的安装目录、资源包 sha256、补丁自检结果，与原机对照即可确认改的是同一处。
