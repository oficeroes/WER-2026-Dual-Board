# 仅 PowerShell 版 —— 「新建项目自带函数库」同步 / 还原工具

> 这个文件夹里的工具**只依赖 Windows 10/11 自带的 Windows PowerShell 5.1**，
> 不需要 Python、Node、不需要联网、不需要安装任何模块。
> 把整个 `WER_函数库` 文件夹拷贝到别的电脑，双击两个 `.cmd` 就能完成同样的修改。

---

## 0. 四个文件是什么

| 文件 | 作用 | 要不要管理员 |
| --- | --- | --- |
| `一键同步(管理员).cmd` | ★ 双击它 = 把「我的函数库」同步进软件的新建项目默认模板（会弹 UAC） | 是（自动请求） |
| `一键还原(管理员).cmd` | ★ 双击它 = 把软件默认模板还原到打补丁之前（会弹 UAC） | 是（自动请求） |
| `同步我的函数库.ps1` | 真正干活的同步脚本（一般不用直接运行，双击上面的 cmd 即可） | 写安装目录时需要 |
| `还原新建模板.ps1` | 真正干活的还原脚本（同上） | 写安装目录时需要 |

> 两个 `.cmd` 的作用只是「请求管理员权限 + 找到同目录对应的 `.ps1` 并运行」，
> 它们故意保持纯 ASCII 内容，避免中文在不同系统代码页下乱码。

## 1. 前提：先有「我的函数库」源文件

同步的源头是 **`WER_函数库\我的函数库.srhs`**（一个普通的 IDE 项目文件）：

1. 打开 AbilixScratch3.0 → 新建项目 → 打开积木编程；
2. 在左侧「函数」分类里用「新建函数」搭你自己的函数（可带参数）；
3. 文件 → 保存，保存/覆盖为 **`WER_函数库\我的函数库.srhs`**（建议别用别的名字）；
4. 关掉软件（同步时 IDE 不能占用安装目录里的资源包）。

> 仓库里已经带了一个**空白模板** `我的函数库.srhs`（只含说明用的主函数 start），
> 你把自己的函数搭进去再保存即可。
> 也支持 `.srh` 纯项目文件；`-Library` 参数可以指定别的路径。

## 2. 一键同步（其他电脑上的完整操作）

1. 把整个 **`WER_函数库`** 文件夹拷到那台电脑上（任意位置都可以，路径有中文/空格也没关系）。
2. 确认那台电脑装了 AbilixScratch3.0，并且**先关闭软件**。
3. 进入 `WER_函数库\工具\仅PowerShell\`，**双击 `一键同步(管理员).cmd`**。
4. 弹出 UAC（用户账户控制）点 **「是」**。
5. 会弹出一个新的管理员 PowerShell 窗口，先自动做 3 项自检，再自动备份、自动写入：
   - 自检 1：解包→原样重打包，必须与原文件**逐字节相同**；
   - 自检 2：除 `Blockly_Code/maingui_init.js` 外，其余 6644 个文件 **sha256 全部一致**；
   - 自检 3：从新包里读回默认模板内容，必须与函数库片段**逐字符相同**。
   看到 `状态：OK 已写入安装目录` 即成功；任何一项自检失败都会**中止、不写入**。
6. 关闭那个管理员窗口 → 重新打开 IDE → **新建项目** → 打开积木编程，
   左侧「函数」分类里就能看到你的函数了（直接拖下来调用）。

> 结果窗口里有：原包 sha256、补丁包 sha256、自动备份文件路径，可以截图留档。
> 换电脑时这份记录也很有用：把「原包 sha256」和「补丁包 sha256」记下来，
> 在其他电脑上同步成功后会得到完全相同的 sha256（相同版本软件 + 相同函数库时）。

### 命令行方式（可选，进阶 / 排查用）

在本文件夹打开 PowerShell（或 cmd）执行：

```bat
:: 只生成补丁包、不安装（演练/取证，安全）
powershell -NoProfile -ExecutionPolicy Bypass -File ".\同步我的函数库.ps1" -Assets "<browser_assets路径>" -Out ".\browser_assets.patched"

:: 安装（需要管理员；在管理员 PowerShell 里执行）
powershell -NoProfile -ExecutionPolicy Bypass -File ".\同步我的函数库.ps1" -Install

:: 指定别的函数库源文件 / 指定别的浏览器资源包（如便携版副本）
powershell -NoProfile -ExecutionPolicy Bypass -File ".\同步我的函数库.ps1" -Library "<我的函数库.srhs>" -Assets "<browser_assets路径>" -Install
```

参数：

| 参数 | 说明 |
| --- | --- |
| `-Assets <路径>` | 手动指定 `browser_assets`（默认自动探测 `C:\ / D:\ Program Files\AbilixScratch3.0\AbilixScratch3.*_Data\Resources\browser_assets`，也认环境变量 `ABILIX_ASSETS`） |
| `-Library <路径>` | 手动指定函数库源 `.srh/.srhs`（默认 `<WER_函数库>\我的函数库.srhs`，找不到再依次找 `.srh` / `WER函数库.srhs` / `示例\WER函数库.srhs`） |
| `-Out <路径>` | 补丁包输出路径（默认 `<本脚本目录>\browser_assets.patched`）；不加 `-Install` 时只生成不安装 |
| `-Install` | 备份后写回 `browser_assets`（安装目录需要管理员；便携版/副本目录可写时普通用户也可以） |
| `-SkipIdenticalCheck` | 跳过「纯 roundtrip 必须逐字节一致」检查（不建议） |
| `-WorkDir <目录>` | 指定临时工作目录（默认系统临时目录，结束自动清理） |
| `-KeepWork` | 保留临时工作目录，排查用 |

## 3. 还原（撤销补丁）

1. 关闭 IDE；
2. 双击 **`一键还原(管理员).cmd`** → UAC 点「是」；
3. 弹窗里会自动找到**最新的** `browser_assets.备份-<时间戳>`，把当前文件另存为
   `browser_assets.还原前备份-<时间戳>`，再用备份覆盖，并校验 sha256；
4. 看到 `状态：OK 已还原` 即成功，重启 IDE 即可。

命令行方式：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File ".\还原新建模板.ps1" -Yes
```

> - 不加 `-Yes` 会先显示将要使用的备份并让你确认；
> - 用 `-Backup <某个browser_assets.备份-...路径>` 可以指定还原到哪一个历史备份；
> - 用 `-Assets <路径>` 可以还原便携版/副本；
> - **每次同步前都会自动把当时的文件备份成 `browser_assets.备份-<时间戳>`**，所以
>   同步→还原→再同步→再还原都不会丢原始文件。

## 4. 日常使用流程（建议）

```
① 在 IDE 里增删改函数 → 保存覆盖  WER_函数库\我的函数库.srhs
② 关闭 IDE
③ 双击 一键同步(管理员).cmd
④ 重新打开 IDE → 新建项目 → 函数分类里就是最新的函数库
```

- **重复同步是安全的**：每次都会重新备份当时的文件，只改 `maingui_init.js` 一个条目；
- **升级 / 重装软件会覆盖补丁**：升级后需要重新同步一次；
- **旧项目不受影响**：补丁只作用于「新建项目」时载入的默认模板；已保存的项目打开后内容不变；
- 只改了**简体中文**的默认模板（`defaultcode`）。如果 IDE 界面语言切成繁体/英文，
  新项目模板是另外两个字符串（`defaultcodeTr`/`defaultcodeEn`），本工具默认不动它们。

## 5. 常见问题（FAQ）

**Q1：双击 cmd 窗口一闪就没了 / 没反应？**
- 先看是否弹了 UAC 但被取消：取消时会提示 `Failed to start elevated PowerShell`；
- 被杀毒软件拦截时请允许；也可右键 cmd →「以管理员身份运行」重试；
- 仍不行就用「管理员 PowerShell」进入本文件夹执行第 2 节里的命令，看具体报错。

**Q2：提示「自动探测不到 AbilixScratch3.0 的 browser_assets」。**
说明软件装在非常规位置。请用 `-Assets "完整的 browser_assets 路径"` 指定；
路径形如 `X:\...\AbilixScratch3.0\AbilixScratch3.0_Data\Resources\browser_assets`
（注意 `AbilixScratch3.0_Data` 中间是**点号**；个别版本是下划线，本工具两种都认）。

**Q3：提示「没有写入权限 / 请用一键同步(管理员).cmd」。**
安装目录在 `Program Files` 下，普通用户只读。必须用“管理员”运行（双击 cmd 自动请求）。
如果公司电脑禁用了 UAC 提升，就只能请管理员操作，或改用 Lead 的「便携版」方案。

**Q4：提示「函数库里必须恰好有 1 个 start 主函数积木块」。**
`我的函数库.srhs` 里 `start`（主函数）积木被删掉了。打开 IDE 把这个项目补一个
`start` 积木（内容可以空着）再保存，然后重新同步。

**Q5：同步成功，但新建项目里没看到函数？**
- 确认是「**新建**项目」，旧项目不会自动加；
- 确认改完补丁后**重启了 IDE**（软件启动时缓存了资源包）；
- 确认用的是**简中界面**（见第 4 节最后一条）；
- 打开 `我的函数库.srhs` 看函数是否真的保存进去了（函数定义块要留在项目顶层）。

**Q6：提示「纯 roundtrip 后字节不一致」。**
说明那个文件不是本工具验证过的 `zfbRes_v1` 布局（可能软件版本不同/文件被改过）。
**不要加 `-SkipIdenticalCheck` 硬来**，先确认软件版本，或改用 Python 参考版排查。

**Q7：提示「不是 zfbRes_v1 资源包」。**
`-Assets` 指错文件了（指到了目录或别的文件），请指向 `...\Resources\browser_assets` 这个**文件**。

**Q8：备份文件越积越多，能删吗？**
`browser_assets.备份-*` 是每次同步前的原始文件（约 85 MB/个），建议保留**最近一个**
再删旧的；`还原前备份-*` 是还原前的文件，确认还原无误后可删。
**不要删除** `browser_assets` 本身。

**Q9：需要 Python 吗？**
不需要。本文件夹就是给没有 Python 的电脑准备的。Python 参考版（等价）在
`WER_函数库\工具\底层\patch_browser_assets.py`，两个版本的产物已验证**逐字节相同**。

**Q10：能对“便携版”副本打补丁吗？**
可以：`-Assets` 指到便携版的 `browser_assets` 即可；目录可写时普通用户也能安装
（脚本会提示「目标目录可写，继续写入」）。还原同理。

## 6. 技术原理（一页说明，便于在其他电脑复现）

1. 软件新建项目时会执行网页端 `maingui.importDefaultCode()`，它读取
   `Blockly_Code/maingui_init.js` 里的 `var defaultcode = '...';` 字符串当作初始工作区。
2. 整个网页资源被打包在安装目录的 `AbilixScratch3_0_Data\Resources\browser_assets`
   文件里，格式为自定义的 `zfbRes_v1`：
   - 文件头：7-bit 长度前缀 + `"zfbRes_v1"`，然后 `Int32 条目数`；
   - 索引：每条 `名字(string) + 数据偏移(Int64) + 数据长度(Int32)`；
   - 数据区：按索引顺序连续存放（无压缩、无对齐填充）。
3. 本工具做的事：
   - 读索引 → 取出 `Blockly_Code/maingui_init.js` → 把 `defaultcode` 的 JS 单引号字符串
     换成「我的函数库」片段（`<xml>根 + <variables> + 全部顶层积木`，必须恰好含 1 个 start）；
   - 按原布局重新打包整个 `browser_assets`：**只改这一条**，其余 6644 条逐字节不变；
   - 三步自检通过后才备份、写入；写回后再校验 sha256。
4. 因此本工具的补丁包与 Python 参考版 `patch_browser_assets.py` 的产物**逐字节相同**
   （证据见 `WER_函数库\证据\PowerShell补丁对比\`）。

## 7. 已知限制

- 只支持 Windows（Windows PowerShell 5.1；Win7 的 5.1 理论可用但未实测）；
- 只改**简体中文** `defaultcode`；繁体/英文模板不动（见第 4 节）；
- 需要能拿到管理员权限（除便携版副本外）；
- 函数名/参数名请用 ASCII（本工具只做同步，不改变 IDE 对中文名会变形的限制）。
