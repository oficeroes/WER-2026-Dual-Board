# WER 函数库 —— 打开积木编程就能直接拖的函数块

> 适用：**AbilixScratch3.0（能力风暴）**，控制器 **SKCON9**，WER 2026 普及赛。
> 目标：把"前进/后退/转弯/巡线到路口/巡线 N 秒/抬升/夹爪/等 Start 键/显示/声音"这些常用动作**提前做成函数块**。
> 打开软件后，左侧工具栏 → **函数** 分类，就能看到并直接拖下来用，不用每次从头搭积木。

## 1. 一分钟上手

### 方式 A（推荐，最简单）：直接打开函数库项目

1. 打开 `AbilixScratch3.0`；
2. 菜单 **文件 → 打开**，选择本项目里的 **`WER函数库.srhs`**；
3. 左侧工具栏点 **函数** 分类 → 里面就是 20 个函数调用块（`func_Init`、`func_ForwardCM` …）；
4. 把 `func_Init` 拖进 `主函数` 第一行；
5. 把 `func_ForwardCM` 拖进主函数，在它右边的参数槽里拖一个 **数字** 块（比如 10）→ 前进 10 厘米；
6. 编译 / 下载到机器人即可。

> 这个项目里已经有一段"示例主程序"（初始化 → 前进 10 厘米 → 右转 90 度 → 停止），
> 你可以直接把它当模板改，也可以删掉示例块，只保留/复制函数定义。

## 2. 函数分类里能看到什么（20 个块）

打开"函数"分类后，按字母顺序排列的调用块（括号里是参数，参数槽要放数字/文本块）：

| 函数块 | 参数 | 作用 |
|---|---|---|
| `func_Init` | 无 | **初始化（每个程序第一步）**：写校准值、读 EEPROM 灰度白值、停车、编码器清零 |
| `func_Stop` | 无 | 左右驱动电机停 |
| `func_ResetEncoder` | 无 | 左右驱动编码器清零 |
| `func_ForwardCM` | `cm` | **前进 cm 厘米**（编码器定距 + 两轮纠偏） |
| `func_BackwardCM` | `cm` | **后退 cm 厘米**（编码器定距 + 两轮纠偏） |
| `func_TurnLeft` | `deg` | **原地左转 deg 度**（编码器定角度） |
| `func_TurnRight` | `deg` | **原地右转 deg 度**（编码器定角度） |
| `func_DriveTime` | `speedL`, `speedR`, `sec` | 左/右电机以指定速度转 sec 秒（到时间自动停） |
| `func_DriveSpeed` | `speedL`, `speedR` | 左/右电机持续转（不停，需配合等待/循环/停止） |
| `func_ArmUp` | 无 | 抬升电机（端口3）正转 `var_arm_time` 秒 |
| `func_ArmDown` | 无 | 抬升电机（端口3）反转 `var_arm_time` 秒 |
| `func_Grab` | 无 | 夹爪/滚筒电机（端口4）正转 `var_arm_time` 秒（取物） |
| `func_Release` | 无 | 夹爪/滚筒电机（端口4）反转 `var_arm_time` 秒（放下） |
| `func_LineTime` | `sec` | **灰度9/10 PID 巡线行驶 sec 秒**，到时间停车 |
| `func_LineUntilCross` | 无 | **巡线到路口**：灰度7 或 灰度8 读到白值（≥ `var_ray_white`）时停车 |
| `func_LineStep` | 无 | 巡线 PID 走一步（内部函数，供上面两个调用；也可自己放进循环） |
| `func_WaitStartKey` | 无 | 等按下主板 **Start（确认）键 1** 再继续（没有该键的车用下面那个） |
| `func_WaitTouch` | 无 | 等**触碰传感器（端口1）**被按下再继续（与主程序.py 的启动方式一致） |
| `func_Show` | `text` | 在机器人屏幕显示一段文字（参数槽放"文本"块） |
| `func_Beep` | 无 | 播放内置提示音 |

> **参数怎么填**：调用块拖出来后，参数槽是空的。从左侧 **数字** 分类拖一个数字块进去（如 10）；
> `func_Show` 的 `text` 槽拖 **文本** 块进去（如 `hello`）。
> **参数槽空着运行时会被当成 None，可能在机器人上报错**，所以每个参数都要填。

### 生成出来的 Python 长什么样

函数块本质就是"函数定义 + 调用"，生成 Python 与手写完全一样。例如主程序里拖：

```
func_Init()
func_ForwardCM(10)
func_TurnRight(90)
func_Stop()
```

会生成：

```python
def main():
    func_Init()
    func_ForwardCM(10)
    func_TurnRight(90)
    func_Stop()
```

`func_ForwardCM` 的定义（软件自动加 `global` 行，这里省略）：

```python
def func_ForwardCM(cm):
    if var_ready == 1:
        pass
    else:
        func_Init()
    func_ResetEncoder()
    while not robot.abs(robot.get_encoder(1)) >= (cm * var_1cm):
        var_enc_diff = (robot.get_encoder(1) - robot.get_encoder(2))
        robot.set_motor(1, robot.clamp((var_speed - (var_straight_Kp * var_enc_diff)), -100, 100))
        robot.set_motor(2, robot.clamp((var_speed + (var_straight_Kp * var_enc_diff)), -100, 100))
        time.sleep(0.01)
    robot.set_motor(1, 0)
    robot.set_motor(2, 0)
    time.sleep(0.05)
```

## 3. 硬件端口假设（重要！）

这些函数按本机 `主程序.py` 的接线推断，默认如下；**如果你的车接线不同，改函数体里的端口数字即可**（点开函数定义块，把端口下拉框改成实际端口）：

| 用途 | 默认端口/通道 | 出现在哪些函数 |
|---|---|---|
| 左驱动电机 | **1** | 所有前进/后退/转弯/巡线/停止 |
| 右驱动电机 | **2** | 同上 |
| 抬升/手臂电机 | **3** | `func_ArmUp` / `func_ArmDown` |
| 夹爪/滚筒电机 | **4** | `func_Grab` / `func_Release` |
| 巡线灰度（左） | **9** | `func_LineStep` |
| 巡线灰度（右） | **10** | `func_LineStep` |
| 路口灰度（左） | **7** | `func_LineUntilCross` |
| 路口灰度（右） | **8** | `func_LineUntilCross` |
| Start/确认键 | **1** | `func_WaitStartKey` |
| 触碰启动/分段键 | **1** | `func_WaitTouch` |
| 巡线计时定时器 | **2** | `func_LineTime` |

> 说明：积木库里"电机端口/灰度通道"是**下拉框字段**，不能接变量，所以只能写成固定数字；
> 要换端口就打开对应函数定义、改下拉框。数值类参数（速度/时间/校准值）都在 `func_Init` 里，改数字即可。

## 4. 校准参数（都在 `func_Init` 里改）

打开 **函数** 分类 → 把 `func_Init` 定义块（不是调用块）找到 → 直接改里面的数字：

| 变量 | 默认值 | 含义 |
|---|---|---|
| `var_1cm` | `90.4` | 1 厘米 = 多少个编码器计数（实测标定；车不同要重标） |
| `var_1angle` | `17.8` | 转 1 度 = 多少个编码器计数（实测标定） |
| `var_speed` | `40` | 直行默认速度 % |
| `var_straight_Kp` | `0.005` | 直行纠偏力度（两轮编码器差值的比例）；走歪了加大 |
| `var_turn_speed` | `25` | 原地转向默认速度 % |
| `var_arm_speed` | `30` | 抬升/夹爪默认速度 % |
| `var_arm_time` | `0.5` | 抬升/夹爪默认持续时间（秒） |
| `var_ray_white` | `1300` | 灰度白值阈值：读数 ≥ 这个值算"白/路口" |
| `var_ray_speed` | `30` | 巡线默认速度 % |
| `var_ray_Kp` | `0.01` | 巡线 PID 比例系数（往哪边偏就调哪边；太大蛇形，太小不纠偏） |
| `var_ray_Kd` | `0.001` | 巡线 PID 微分系数（抑制摆动） |

### 关于灰度白值 / EEPROM

- `func_Init` 会执行 `robot.get_ee(9)` / `robot.get_ee(10)` 读 **EEPROM 9/10** 里的灰度白值；
  这两个值由本机标定程序（历史程序 `experiment.py`，见项目 `逆向资料/样本程序/`）写入。
- 如果没标定过（读到 < 100），函数会自动退回默认 **1300**，程序不会崩；但巡线效果取决于实际场地，建议：
  1. 先跑一次标定程序；或
  2. 直接把 `func_Init` 里 EEPROM 那两行换成固定数字（把 `robot.get_ee(9/10)` 改掉不方便的话，就把后面 fallback 的 1300 当默认值微调）。
- 巡线方向如果反了（越走越偏），把 `var_ray_Kp` 改成负数试试（或检查左右灰度是否接反）。

**任务：从起点沿黑线走到第一个路口**

## 6. 限制与注意事项（务必看）

1. **函数没有返回值**：这套"函数"分类只支持无返回值函数（软件本身的限制），所以不能用函数当条件；
   要读传感器，直接用左侧 **传感器** 分类的积木（灰度/触碰/超声都在）。
2. **参数槽必须填**：空参数 = `None`，机器人上可能报类型错误。数字块、变量块、运算块都可以放进参数槽。
3. `func_ForwardCM` / `func_BackwardCM` / `func_TurnLeft` / `func_TurnRight` 的参数**填正数**；
   方向由函数本身决定（前进/后退、左转/右转）。
4. 每个动作函数开头有"未初始化就自动初始化"的保护（`if var_ready == 1 ... else func_Init()`），
   所以忘了放 `func_Init` 也能跑；但**仍然建议第一行放 `func_Init`**，方便阅读、避免重复初始化。
5. 函数之间会**互相调用**（`func_ForwardCM` 会调 `func_ResetEncoder`、`func_Init`），
   移动/删除函数定义时要一起处理，否则调用块会变成"孤立块"（IDE 会提示/自动删）。
6. 所有 `global var_...`、末尾 `pass`、`var_xxx = None` 都是软件生成器的样板，不是手写内容。
7. **真机首次使用前**：先在软件里"编译"看代码是否正常、再下载；第一次建议把车架起来空转确认电机方向/端口。
8. 本项目未改动软件安装目录（除方式 D 由你手动运行的管理员补丁）；函数库只影响"打开/合并进的项目"。
